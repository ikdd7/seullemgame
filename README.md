# 공무원 특화 AI 면접 시스템 🏛️

**지자체 × 직렬 맞춤 모의면접** — 응시자가 실제 지원하는 지역(17개 시·도 + 기초)과 직렬의
면접 방식·평정요소·지역현안을 그대로 재현하는 공무원 특화 AI 모의면접 시스템의 데이터·설계 저장소.

이 저장소는 **면접 자료 수집**에서 출발해 **구조화 데이터셋 → 시스템 아키텍처 설계 → 실행 가능한 프로토타입**까지 진행됐다.
일반 AI 면접 서비스가 "범용 인성·직무 질문 + 표정/음성 점수화"에 머무는 것과 달리, 실제 공무원 면접의
**제도(국가직 9급형 / 지방직 표준형 / 지자체별 변형)**, **평정 규칙(위원 과반수 상·중·하 임계 판정)**,
**꼬리질문 압박(위원 페르소나 기반)** 을 정확히 모사하는 것을 목표로 한다.

> 수집 라운드별 진행 로그는 [`PROGRESS.md`](./PROGRESS.md) 참고. 이 README는 저장소 현황과 사용법의 마스터 인덱스다.

## 구조화 데이터 (`data/07-structured/`)

마크다운 원본은 **읽기 전용**이며, 아래 두 스크립트가 이를 파싱해 JSON을 재생성한다(외부 의존성 없음, 결정적).
스키마·파서 한계 전문은 [`data/07-structured/README.md`](./data/07-structured/README.md), 통계 분석은 [`데이터셋-리포트.md`](./data/07-structured/데이터셋-리포트.md).

### `questions.json` — 질문 뱅크
재생성: `python3 scripts/build_dataset.py`

| 필드 | 설명 |
|---|---|
| `id` | `q00001` 형식 일련번호(정렬 순서 기반, 재생성 시 밀릴 수 있음) |
| `text` | 질문·발표주제 본문(마커 제거·NFC 정규화·편집 주석 꼬리 제거) |
| `category` | `common` / `region` / `job` (원본 디렉토리 기반) |
| `region` | 지역명(파일명·섹션 제목·태그 추출, 약칭→공식명 정규화). 없으면 null |
| `job` | 직렬명(파일명·섹션 제목·태그 추출). 없으면 null |
| `year` | 출제(복원) 연도. 미상이면 null (약 94% 미상) |
| `type` | `공직가치`/`인성`/`직무`/`지역현안`/`상황형`/`시사`/`발표`/`후속` |
| `reliability` | `확인`/`복원`/`기출`/`빈출`/`예상` (저작권·신뢰도 태그, 아래 [주의사항](#데이터-주의사항) 참고) |
| `source_file` | 원본 마크다운 경로 |

### `region_context.json` / `job_context.json` — 질문 생성 컨텍스트
재생성: `python3 scripts/build_context.py`

질문 생성 프롬프트에 바로 주입할 "핵심 컨텍스트"를 뽑은 구조화 JSON. 배치 파일은 헤딩별로 개별 엔트리로 분해.
- **지역(147개)**: `region`·`면접방식요약`·`시정비전`·`슬로건`·`핵심사업[]`·`지역현안[]`·`source` (민선 9기·2026.7 기조 반영)
- **직렬(37개)**: `job`·`개요`·`주요업무[]`·`법령키워드[]`·`핵심제도[]`·`source`

## 프로토타입 실행 (`data/08-system/prototype/`)

### `question_selector.py` — 질문 출제(선택) 엔진 ✅ 실행 검증됨
설계 문서(모의면접 세션 설계 §3, 아키텍처 §4-1)의 질문 선택 알고리즘을 표준 라이브러리만으로 구현.
유형 쿼터 → 완화단계 후보 필터(지역+직렬 → 축 분리 → 공통) → 가중 샘플링 → 중복 제거 → 출제 순서 배치.

```bash
cd data/08-system/prototype

# 기본 (지방직 표준 트랙, 실전 모드, seed=42)
python3 question_selector.py --region 서울특별시 --job 일반행정직

# 트랙/난이도/시드 지정
python3 question_selector.py --region 부산광역시 --job 사회복지직 --track 지방직표준 --difficulty 초급 --seed 7

# 국가직 9급형 (지역현안 제외, 상황형 강화)
python3 question_selector.py --region 서울특별시 --job 일반행정직 --track 국가직9급

# JSON 출력 (파이프라인 연동용)
python3 question_selector.py --region 경기도 --job 전산직 --json
```

사용법·알고리즘·검증 결과 전문은 [`prototype/README.md`](./data/08-system/prototype/README.md).
지역×직렬 동시 태깅이 전체의 3.4%로 희소하므로, "지역 축(지역현안) + 직렬 축(직무)을 각각 뽑아 조합"하는 것이 핵심 설계다.

### 세션 엔진 · 채점기 (설계 완료, 프로토타입 예정)
INTERVIEW 대화 루프(꼬리질문 트리거)와 위원 앙상블 채점·피드백 생성은 **설계·프롬프트 실장까지 완료**됐고,
`question_selector.py`에 이어 다음 프로토타입 대상이다. 실행 사양은 설계 문서로 확정돼 있다.
- 세션 오케스트레이션(INTAKE → PREWORK → SPEECH → INTERVIEW → WRAPUP): 아키텍처 §4-2
- 채점(위원 N인 앙상블, 상/중/하 → 우수/보통/미흡, red flag, 근거 인용) + 피드백: [`채점-프롬프트-실장.md`](./data/08-system/채점-프롬프트-실장.md) §1·§2·§4

## 데이터 주의사항

- **복원 기출은 응시자 후기 기반**: 공무원 면접 문제지는 공식 비공개이므로, 수집된 기출은 응시자 복원 후기에 근거한다. 원문과 정확히 일치하지 않을 수 있다.
- **신뢰도 태그(`reliability`)의 의미**:
  - `확인`(96) · `복원`(234) · `기출`(129) = **고신뢰 459건(14.2%)** — 출처에서 확인됐거나 실제 출제로 검증된 항목.
  - `빈출`(440) — 단골·빈출로 표기된 중간 신뢰.
  - `예상`(621) — 현안 기반으로 모델/편집자가 **생성·추정**한 항목. AI 노출 시 "실제 출제 아님"으로 구분해 워밍업·연습용으로 사용.
  - 미태깅(1,720, 약 53%) — 신뢰도 불명이므로 보수적으로 취급. 주로 직렬 직무 체크리스트 질문.
- **저작권·라이선스**: 상용 서비스 반영 시 출처별 라이선스(공공누리 여부 등)를 반드시 확인. 출처별 신뢰도·저작권 주의는 [`00-sources.md`](./data/00-sources.md).
- **시점 반영**: **2026.6 지방선거(민선 9기)** 결과와 **2026.7.1 통합특별시 출범**(전남·광주 통합 등)을 지역 컨텍스트·현안 질문에 반영. 지역별 시정비전·슬로건·단체장 정보는 이 시점 기준이다.
- **알려진 한계**: `region` 값에 `중소시군-3차`·`군단위-호남` 등 수집 배치 라벨이 유입돼 지역 필터 정확도가 낮고, 지역×직렬 교차 태깅은 3.4%로 희소하다. 상세는 [`데이터셋-리포트.md`](./data/07-structured/데이터셋-리포트.md) §3~4.

## 로드맵 (아키텍처 종합설계 §5)

**핵심 원칙: 텍스트 기반 모의면접부터. 음성·영상은 후순위.**

- **MVP — 텍스트 모의면접** — 채팅 UI로 전 흐름(질문·채점·피드백)의 가치를 먼저 검증.
  지방직 표준형 1종(+서울 프로파일), questions.json 필터·쿼터 샘플링, INTERVIEW 루프 + 꼬리질문 일부, 위원 2인 앙상블 채점(상/중/하 → 우수/보통/미흡), 근거 인용 피드백. STT/TTS·영상·결제 제외.
- **v1 — 음성 모의면접 + 지자체 확장** — 리턴제로 STT·Silero VAD·하이브리드 TTS, 스피치 지표(말속도·필러·침묵), 국가직 9급형·부산·대구·경기 프로파일, T1~T7 꼬리질문 + 위원 3인, 초급/실전 난이도, 결제·환불 약관.
- **v2 — 영상·고급 재현·데이터 고도화** — MediaPipe 온디바이스 표정/시선(코칭 전용·등급 미반영), WebRTC 전환, 인천 모의토론(AI 토론자), 골든셋 회귀 자동화, 지역×직렬 교차·표본부재 직렬(소방·교정) 데이터 보강, 인간 평가자 상관 측정·공개.

> 공정성·규제 설계는 전 단계 내장: 비언어는 등급 미반영, 블라인드 원칙, AI 생성물 고지, 만 14세 확인, 국외이전 고지.

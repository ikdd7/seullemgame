# 공무원 특화 AI 면접 시스템 — 자료 수집 저장소 🏛️

지자체별·직렬별 공무원 면접 자료를 수집·정리하는 저장소입니다.
AI 면접 시스템(질문 생성 + 답변 평가)의 학습/프롬프트 컨텍스트로 사용할 데이터를 모읍니다.

## 구조

```
data/
├── 00-sources.md              # 전체 출처 목록 및 데이터셋/API 안내
├── 01-evaluation-criteria/    # 면접 평가기준 (국가직/지방직 공식 평가요소)
├── 02-common/                 # 공통 질문 (공직가치·인성·상황형·5분발표 등)
├── 03-regions/                # 지자체별 면접 자료 (17개 시·도 + 주요 기초지자체)
├── 04-jobs/                   # 직렬별 면접 자료 (행정·사회복지·기술직 등)
└── 05-datasets/               # 외부 AI 학습 데이터셋/오픈API 안내
```

## 데이터 형식

각 파일은 마크다운으로 작성하며 다음을 포함합니다:

- **질문**: 연도·직렬·유형(공직가치/직무/지역현안/인성) 태그
- **출처**: 수집한 웹페이지 URL (복원 기출은 응시자 후기 기반임을 명시)
- **지역 컨텍스트**: 해당 지자체의 시정목표·핵심과제·지역현안 (질문 생성용)

## 주의사항

- 면접 문제지는 공식 비공개이므로, 여기 수집된 기출은 **응시자 복원 후기 기반**입니다.
- 상용 서비스 반영 시 출처별 라이선스(공공누리 여부 등)를 반드시 확인하세요.

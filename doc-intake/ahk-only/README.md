# 문서접수 OCR 자동입력 — AutoHotkey 전용 (Python 불필요)

**Python 설치 없이 AutoHotkey만으로** 스캔/PDF 문서를 읽어 문서접수 GUI에 자동 입력합니다.
Windows에 내장된 OCR 엔진(Windows.Media.Ocr)을 사용하므로, **추가 프로그램 설치가 필요 없어요.**
(이미 쓰고 계신 매크로처럼 `.ahk` 파일만 추가하면 됩니다.)

> ## ⛔ 가장 중요한 규칙
> **이 폴더의 파일들(OCR.ahk · 문서추출엔진.ahk · 대상물DB.csv · 각 .ahk)은 항상 같은 폴더에 함께 있어야 합니다.**
> 한 파일만 다른 곳(바탕화면 등)으로 옮기면 `#Include ... cannot be opened` 오류가 납니다.
> 폴더째로 옮기는 건 OK, 파일 하나만 따로 빼는 건 NO.

> ## 📌 이 PC는 '파일 선택 창'이 막혀 있음
> 보안정책으로 파일 선택 대화상자·드래그가 차단된 환경이라, **스캔 폴더의 '최신 PDF'를 자동으로
> 집어오는 방식**을 씁니다. 스캔 폴더 경로는 각 .ahk 상단 `SCAN_FOLDER` 에 지정
> (현재: `C:\Users\User\Desktop\scan`).

## 들어있는 파일

| 파일 | 역할 |
|---|---|
| `OCR.ahk` | Windows 내장 OCR 라이브러리 (Descolada, 오픈소스) — 건드릴 필요 없음 |
| `문서추출엔진.ahk` | PDF 읽기 + 필드 추출 + DB 보정 핵심 로직 — 건드릴 필요 없음 |
| `OCR테스트.ahk` | **먼저 이걸로 시험** — 더블클릭 → PDF 고르면 추출 결과를 보여줌 |
| `문서접수_OCR연동.ahk` | 기존 매크로 GUI에 붙이는 연동 파일 |
| `대상물DB.csv` | 대상물 목록 (OCR 오타 자동 교정용) |

## ⚠️ 딱 하나 확인할 것: 한국어 OCR 설치 여부

Windows에 **한국어 OCR**이 깔려 있어야 합니다. (한국어 윈도우는 대부분 이미 있음)

확인/설치: **설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → ⋯ → 언어 옵션 →
'광학 문자 인식(OCR)'** 항목이 설치돼 있으면 OK. 없으면 거기서 설치(무료, 클릭 한 번).

> 설치 권한이 막혀 있어도, OCR 언어는 보통 **언어팩 안에 포함**돼 별도 관리자 권한 없이 켜지는 경우가 많아요.
> `OCR테스트.ahk` 를 돌렸을 때 "한국어 OCR이 없습니다" 메시지가 안 뜨면 정상입니다.

## 사용 순서

### 1단계 — 먼저 테스트 (폴더 통째로 둔 상태에서)
1. 스캔 폴더(`C:\Users\User\Desktop\scan`)에 시험할 PDF가 있는지 확인.
2. 이 폴더 안의 **`OCR테스트_폴더.ahk` 더블클릭** → 스캔 폴더의 최신 PDF를 자동으로 읽어 결과 표시.
   (파일 선택 창 안 뜸. 대상물명·주소·부서가 잘 나오는지 확인, 스캔이면 몇 초 소요)
   ※ 이때 `OCR.ahk`·`문서추출엔진.ahk`·`대상물DB.csv`가 **같은 폴더**에 있어야 함.

### 2단계 — 매크로에 연동
1. `OCR.ahk` · `문서추출엔진.ahk` · `대상물DB.csv` · `문서접수_OCR연동.ahk` 를
   **매크로 폴더(`문서접수_main.ahk` 가 있는 곳)** 에 **함께** 복사 (흩어지지 않게!).
2. `문서접수_OCR연동.ahk` 상단 `SCAN_FOLDER` 가 스캔 폴더 경로와 맞는지 확인.
3. `문서접수_main.ahk` 에 한 줄 추가:
   ```autohotkey
   #Include 문서접수_OCR연동.ahk
   ```
4. (선택) `문서접수_GUI.ahk` 하단 버튼 줄에 추가:
   ```autohotkey
   global btnPdf := myGui.Add("Button","x390 y" . btnY . " w160 h32 -TabStop","📄 스캔 불러오기")
   btnPdf.OnEvent("Click", OnLoadPDF)
   ```
   버튼을 안 넣어도 **단축키 `F9`** 로 바로 됩니다.

### 동작 흐름
```
문서 스캔(→ 스캔 폴더에 PDF 저장) → [F9] 또는 [📄 스캔 불러오기]
  → 스캔 폴더의 '최신 PDF' 자동 선택
  → Windows OCR로 읽기 (+대상물DB 오타 보정)
  → 추출 결과 미리보기 확인창
  → '예' → GUI 빈 행에 자동 입력
  → 기존 F6/F7/F8 접수 자동화로 진행
```

## 대상물DB.csv (정확도의 핵심)

OCR이 고유명사를 한 글자 틀려도(예: `변로로파크`), DB에 `뽀로로파크`가 있으면 **자동 교정**됩니다.
관할 대상물을 한 줄씩 추가할수록 정확도가 거의 100%에 수렴해요.

```csv
대상물명,주소,부서
월드프라자,인천광역시 중구 경동 74 (개항로 112),중부소방서 예방안전과
뽀로로파크,인천광역시 중구 월미로 222,중부소방서 예방안전과
```
- `대상물명` 만 있어도 OCR 결과를 교정함(유사도 50% 이상 매칭).
- `주소`·`부서` 까지 채워두면 매칭 시 그 값으로 정확히 입력됨.
- ⚠️ 각 칸 안에 **쉼표(,) 는 넣지 마세요** (CSV 구분자라 깨집니다).

## 한계 / 메모

- 사람 이름(관계인)은 DB에 없으면 OCR 원문이라 가끔 한 글자 틀릴 수 있음 → 확인창에서 수정.
- 작동/종합 체크 표시는 스캔 OCR로 100% 구분이 어려워 **기본 '작동'** 으로 두니, 확인창에서 점검.
- 스캔 품질이 낮으면 인식률이 떨어짐 → 300dpi 이상 권장.
- Windows 내장 OCR 정확도는 EasyOCR/PaddleOCR보다 약간 낮지만, **DB 보정 + 확인창**으로 실무 사용에 충분.
- 같은 폴더의 상위 `../extract_doc.py`(Python 버전)는 디지털 PDF에서 100% 정확 — 나중에 Python을 쓸 수 있게 되면 그쪽이 더 좋습니다.

# 문서접수 OCR 자동입력 (doc-intake)

스캔/PDF로 들어온 **소방 자체점검 관련 문서**를 읽어, 기존 문서접수 매크로(AutoHotkey GUI)의
입력 필드(관계인·대상물명·주소·부서·작동/종합)를 **자동으로 채워주는** 도구입니다.

## 지원 문서

| 문서 | 종류 | 추출 방식 | 정확도 |
|---|---|---|---|
| 소방시설등 자체점검 **실시결과 보고서** | 디지털 PDF(텍스트 O) | 좌표 기반 직접 추출 | ★★★★★ (~100%) |
| 자체점검 결과 **이행계획서** | 스캔(이미지) | EasyOCR + DB 보정 | ★★★★☆ |
| 자체점검 결과 **이행완료 보고서** | 스캔(이미지) | EasyOCR + DB 보정 | ★★★★☆ |

> 디지털 PDF는 글자 좌표가 그대로 있어 거의 100% 정확. 스캔본은 OCR이라 고유명사에서
> 가끔 한 글자 오타가 나는데, **대상물DB.csv 유사도 매칭으로 자동 보정**한다.
> (실측 예: OCR이 `변로로파크`로 읽어도 DB의 `뽀로로파크`로 자동 교정됨)

## 설치 (자기 PC에서 1회)

```bash
# 1) 파이썬 3.9+ 설치되어 있어야 함
# 2) 의존성 설치
pip install -r requirements.txt
```

처음 스캔 문서를 돌릴 때 EasyOCR 한국어 모델이 한 번 자동 다운로드된다(이후 오프라인 동작).

## 단독 사용 (추출만 확인)

```bash
python extract_doc.py "C:\scan\이행완료 보고서(뽀로로파크).pdf"
```

출력 예:
```
────────────────────────────────────────
  문서종류  : 이행완료보고서
  대상물명  : 뽀로로파크
  주소     : 인천광역시 중구 월미로 222
  관계인   : 김관회
  전화번호  : 010-8115-9583
  점검종류  : 작동
  부서     : 중부소방서 예방안전과
  추출방식  : ocr
  DB매칭   : 뽀로로파크 (유사도 80%)
────────────────────────────────────────
```

옵션:
- `--ini out.ini` : AHK가 읽을 INI 파일로 저장
- `--json out.json` : JSON으로 저장
- `--db 대상물DB.csv` : 대상물 DB 경로 지정(기본값: 같은 폴더의 `대상물DB.csv`)

## 대상물 DB (`대상물DB.csv`)

OCR 오타 보정과 주소·부서 자동 채움에 쓰인다. 관할 대상물을 한 줄씩 추가하면 정확도가 올라간다.

```csv
대상물명,주소,부서
월드프라자,인천광역시 중구 경동 74 (개항로 112),중부소방서 예방안전과
뽀로로파크,인천광역시 중구 월미로 222,중부소방서 예방안전과
```

- `대상물명`만 있으면 OCR 결과와 유사도 매칭해 교정한다(유사도 50% 이상).
- `주소`·`부서`까지 채워두면, 매칭 시 그 값으로 **덮어써서** 스캔 오타 없이 정확하게 들어간다.

## 매크로(AHK) 연동

`ahk/문서접수_OCR연동.ahk` 를 기존 매크로에 붙인다.

1. **경로 설정** — `문서접수_OCR연동.ahk` 상단의 `PY_EXE` / `PY_SCRIPT` / `PY_DB` 를 본인 PC 경로로 맞춘다.
2. **모듈 포함** — `문서접수_main.ahk` 에 한 줄 추가:
   ```autohotkey
   #Include 문서접수_OCR연동.ahk
   ```
3. **버튼 추가(선택)** — `문서접수_GUI.ahk` 하단 버튼 줄에:
   ```autohotkey
   global btnPdf := myGui.Add("Button","x390 y" . btnY . " w160 h32 -TabStop","📄 PDF 불러오기")
   btnPdf.OnEvent("Click", OnLoadPDF)
   ```
   버튼 없이 **단축키 `F9`** 로도 바로 호출된다.

### 동작 흐름
```
[F9] 또는 [📄 PDF 불러오기]
   → 스캔/PDF 파일 선택
   → extract_doc.py 실행 (디지털=좌표추출 / 스캔=EasyOCR)
   → 대상물DB 유사도 보정
   → 추출 결과 미리보기 확인창
   → '예' 누르면 GUI의 빈 행에 자동 입력
   → 기존 F6/F7/F8 접수 자동화로 이어서 진행
```

확인창을 한 번 거치므로, 스캔 OCR 오타가 있어도 입력 전에 눈으로 점검·수정할 수 있다.

## 한계 / 메모

- 사람 이름(관계인)은 DB에 없으면 OCR 원문 그대로라 가끔 한 글자가 틀릴 수 있다 → 확인창에서 수정.
- 스캔 품질이 너무 낮으면 인식률이 떨어진다. 가능하면 300dpi 이상 권장.
- 더 높은 정확도가 필요하면 PaddleOCR(무료·오프라인)로 교체 가능(추출 로직은 그대로 재사용).

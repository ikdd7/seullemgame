# 공무원 AI 면접 연습 서비스 — 법적 컴플라이언스 조사

> 수집일: 2026-07-05

> **면책 고지**: 이 문서는 웹 공개 자료와 법령 정보를 기반으로 정리한 **조사 자료**이며, **법률 자문이 아님**. 실제 서비스 출시 전에는 반드시 IT/개인정보 전문 변호사의 검토를 받을 것. 법령 조문 번호와 내용은 국가법령정보센터(law.go.kr) 게재 법령 및 이를 인용한 로펌 뉴스레터·해설 자료를 교차 확인해 정리했으나, 시행령·고시가 계속 제정·개정 중이므로 출시 시점에 최신 상태를 재확인해야 함.

**서비스 전제**: 공무원 수험생 대상 "AI 면접 연습(모의 면접)" 서비스. 실제 채용 결정을 하지 않는 B2C 연습·교육 서비스라는 점이 규제 강도를 크게 낮추는 핵심 포인트. 다만 음성·영상 수집, LLM API 활용, 유료 결제가 있으므로 개인정보·전자상거래 규제는 정면으로 적용됨.

## 1. AI 기본법 (인공지능 발전과 신뢰 기반 조성 등에 관한 기본법)

- **정식 명칭**: 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 (법률 제20676호, 2025.1.21. 제정)
- **시행일**: **2026.1.22. 전면 시행** (시행령: 대통령령 제36053호, 2026.1.21. 제정, 같은 날 시행)
- EU AI Act에 이어 세계 두 번째 수준의 포괄적 AI 규제 체계. 국내 이용자 대상이면 해외 사업자에게도 적용(역외 적용, 일정 기준 이상 해외 사업자는 국내대리인 지정 의무).

### 1-1. '고영향 인공지능' 해당 여부 — 채용 분야 명시됨

- 제2조 제4호: "고영향 인공지능"이란 사람의 생명, 신체의 안전 및 기본권에 중대한 영향을 미치거나 위험을 초래할 우려가 있는 인공지능시스템으로서 각 목의 영역에서 활용되는 것.
- 각 목에 **"채용, 대출 심사 등 개인의 권리·의무 관계에 중대한 영향을 미치는 판단 또는 평가"** 영역이 **명시**되어 있음 (에너지, 먹는 물, 보건의료, 원자력, 범죄 수사(생체인식), 채용·대출심사, 교통, 공공서비스(급부 결정), **교육**(학생 평가) 등 총 11개 영역).
- **우리 서비스 판단 (조사자 의견, 확정적 결론 아님)**:
  - 실제 채용 합격/불합격을 결정하지 않는 **연습·훈련 서비스**는 "개인의 권리·의무 관계에 중대한 영향을 미치는 판단 또는 평가"에 해당한다고 보기 어려움 → 고영향 AI 비해당 가능성이 높음.
  - 시행령은 고영향 여부를 **사용 영역 + 기본권에 대한 위험의 영향·중대성·빈도**를 종합 고려해 판단하도록 규정. 사전 일괄 지정이 아니라 **사업자 신청 기반 '고영향 인공지능 확인' 절차**(과기정통부, 기본 30일 + 30일 연장 가능)가 마련되어 있음.
  - 유의: '교육' 영역(학생 평가 등)도 고영향 목록에 있으므로, 서비스가 "점수화된 평가 결과"를 제공하고 이를 학원·기관이 수강생 관리에 쓰는 B2B 확장을 하면 재검토 필요.
  - 애매하면 계도기간 중 과기정통부 **고영향 AI 확인 신청**으로 공식 확인을 받아두는 것이 가장 안전한 경로.

### 1-2. 사업자 의무 (해당 시)

- **투명성 확보 의무 (제31조)** — 고영향 AI 여부와 별개로 **생성형 AI를 쓰면 적용**:
  1. 고영향 또는 생성형 AI 기반 제품·서비스 제공 시, AI 기반으로 운용된다는 사실을 **사전 고지** (약관 명시, 화면 표시, 팝업·알림 등 가능).
  2. 생성형 AI 산출물임을 이용자가 명확히 인식할 수 있도록 **고지 또는 표시** (AI 생성물 표시 의무).
  - 과기정통부 「인공지능 투명성 확보 가이드라인」(2026.1. 공개): 의무 주체는 이용자에게 직접 서비스하는 '인공지능사업자'(해외 사업자 포함). 산출물이 **서비스 환경 내에서만 제공되는 경우 외부 반출 시와 구분해 유연한 표시 허용**.
  - → **우리 서비스는 LLM으로 질문·피드백을 생성하므로 이 의무는 사실상 적용 대상**. "본 서비스의 질문/피드백은 생성형 AI가 생성합니다" 고지 + 결과 화면 내 표시로 이행 가능.
- **안전성 확보 의무 (제32조)**: 누적 연산량 일정 기준 이상의 초거대 모델 학습 사업자 대상 → 자체 모델을 학습하지 않는 API 이용 사업자에게는 해당 없음.
- **고영향 AI 사업자 책무 (제34조)** — 고영향에 해당할 경우: ① 위험관리방안 수립·운영, ② 산출 결과에 대한 설명 방안(주요 판단 기준 포함) 마련, ③ 이용자 보호 방안, ④ 사람에 의한 관리·감독, ⑤ 안전성·신뢰성 확보 조치 확인 문서 작성·보관 등.
- **제재**: 사전 고지 의무 위반, 국내대리인 미지정, 시정명령 미이행 시 **3천만원 이하 과태료** (제43조). 표시 의무 위반은 시정명령(제40조) 후 미이행 시 과태료.

### 1-3. 계도기간

- 과기정통부는 **최소 1년 이상 규제 적용 유예(계도기간)** 운영 방침 공표. 계도기간 중에는 사실조사·과태료 부과를 유예하고 안내·컨설팅 중심 운영.
- → 2026~2027년 초까지는 제재 리스크가 낮지만, 신생 서비스라면 처음부터 투명성 고지를 넣는 것이 비용이 거의 들지 않으므로 즉시 이행 권장.

## 2. 개인정보보호법

### 2-1. 음성·영상 수집 동의

- 면접 연습 중 녹음·녹화되는 음성·영상은 개인을 식별할 수 있는 **개인정보**. 수집·이용 시 제15조에 따라 목적, 항목, 보유·이용 기간, 동의 거부권 및 불이익을 알리고 동의를 받아야 함.
- 회원가입 동의와 별개로, 녹음·녹화가 시작되는 시점에 **명확한 인지(녹화 표시 등)**를 주는 UX 권장.
- AI 모델 개선(학습) 목적으로 이용하려면 **수집 목적과 별도로 특정하여 고지·동의**하거나 가명처리 경로(아래 2-4) 사용. 개인정보보호위원회 「생성형 AI 개발·활용을 위한 개인정보 처리 안내서」(2025.8.)가 실무 기준.

### 2-2. 생체인식정보 (민감정보) 규제

- 시행령 제18조 제3호: 민감정보인 생체인식정보 = "개인의 신체적, 생리적, 행동적 특징에 관한 정보로서 **특정 개인을 알아볼 목적으로** 일정한 기술적 수단을 통해 생성한 정보" (얼굴, 음성, 지문, 홍채, 걸음걸이 등).
- **핵심 분기점**: '특정 개인을 알아볼 목적'(인증·본인확인)이 있어야 민감정보. 
  - 표정·시선·목소리 톤을 **평가/피드백 목적**으로만 분석하고 개인 식별·인증에 쓰지 않으면 민감정보가 아닐 수 있음(개보위 「생체정보 보호 가이드라인」의 생체인식정보/일반 생체정보 구분).
  - 반대로 **얼굴·음성으로 본인확인**(부정 사용 방지, 로그인)을 구현하면 민감정보 → 제23조에 따라 **별도 동의** + 안전성 확보조치 필요.
- 보수적으로는 영상 분석 기능 도입 시 민감정보 수준의 별도 동의·암호화·접근통제를 갖추는 것이 안전.

### 2-3. 자동화된 결정에 대한 정보주체 권리 (제37조의2)

- 2023.3.14. 개정으로 신설, **2024.3.15. 시행**. 완전히 자동화된 시스템(AI 포함)에 의한 결정이 정보주체의 **권리·의무에 중대한 영향**을 미치는 경우:
  - 정보주체는 해당 결정에 대한 **거부권** 및 **설명·검토 요구권** 보유.
  - 개인정보처리자는 정당한 사유가 없는 한 인적 개입 재처리·설명 등의 조치 의무, 자동화된 결정의 기준·절차를 공개해야 함.
  - 개보위 「자동화된 결정에 관한 정보주체의 권리에 관한 고시」 및 안내서 제정(2024).
- **우리 서비스 적용**: 연습 피드백 점수는 "권리·의무에 중대한 영향을 미치는 결정"이 아니므로 거부권의 직접 적용 대상이 아닐 가능성이 큼. 실제 AI 채용에서도 사람이 의사결정에 개입하면 '완전히 자동화된 결정'이 아님. 다만 **자동화된 처리의 기준·절차를 개인정보 처리방침에 공개**해 두면 신뢰 측면에서 유리.

### 2-4. 가명처리

- 제28조의2: **통계작성, 과학적 연구, 공익적 기록보존** 목적이면 정보주체 동의 없이 가명정보 처리 가능. '과학적 연구'에는 기술 개발·실증, 민간 투자 연구 포함 → AI 모델 개선이 포섭될 여지.
- 음성·영상 같은 **비정형데이터 가명처리** 기준은 개보위 「가명정보 처리 가이드라인」 개정(2024.2.)으로 마련됨(얼굴 마스킹, 음성 변조 등). 실무적으로 비정형데이터 가명처리는 난이도가 높으므로, 학습 활용은 **명시적 별도 동의(옵트인)** 방식이 더 간명함.

### 2-5. 만 14세 미만

- 제22조의2: 만 14세 미만 아동의 개인정보 수집 시 **법정대리인 동의 + 동의 여부 확인 의무** (휴대전화 본인인증, 신용카드 정보 등 시행령상 확인 방법). 위반 시 5년 이하 징역/5천만원 이하 벌금 또는 매출액 3% 이하 과징금.
- 공무원 응시 연령이 18세 이상(교정·보호직 20세)이므로 실사용자가 만 14세 미만일 가능성은 사실상 없음 → **회원가입 시 "만 14세 이상" 확인 절차를 두고 미만은 가입 차단**하는 것이 가장 간단한 컴플라이언스.

### 2-6. 국외 이전 (LLM API 사용 시) — 실무상 중요

- OpenAI/Anthropic 등 해외 LLM API로 이용자의 답변 텍스트·음성을 전송하면 **개인정보 국외 이전(제28조의8)** 이슈 발생.
- 허용 근거: ① 별도 동의, ② 법령·조약, ③ **계약 이행을 위한 처리위탁·보관으로서 처리방침 공개 또는 고지**, ④ 인증받은 자, ⑤ 적정성 인정 국가.
- 실무: 서비스 제공에 필수적인 위탁이면 **개인정보 처리방침에 국외 이전 항목(이전받는 자, 국가, 항목, 목적, 보유기간 등)을 공개**하는 방식으로 대응 가능. 처리방침에 누락 시 제28조의8 위반 소지(실제 개보위 처분례 존재). 모델 제공사의 "학습에 미사용(zero retention)" 설정·계약 확인 필요.

## 3. 채용절차법 (채용절차의 공정화에 관한 법률)

- **AI 면접을 직접 규율하는 조항은 현행법에 없음**. 21대 국회에서 AI 채용 고지 의무 등 개정안 다수 발의 → 임기만료 폐기. 2023년 전면개정안('공정채용법')도 폐기 후 재발의 논의 중 (2025~2026 개정 쟁점: AI 채용 시 사전 고지, 설명 요구 등). 입법 동향 모니터링 필요.
- 적용 범위(제3조): **상시 30명 이상 근로자 사용 사업장**의 채용절차. **국가·지자체의 공무원 채용에는 적용되지 않음**.
- **우리 서비스 판단**: 우리는 '구인자'가 아니고 채용 결정을 하지 않는 연습 서비스이므로 **직접 적용 없음**. 참고 규정:
  - 거짓 채용광고 금지, 채용광고 내용의 불리한 변경 금지
  - 직무와 무관한 개인정보(용모·키·체중, 출신지역, 혼인 여부, 가족의 학력·직업 등) 수집 금지(제4조의3) → **연습용 질문 생성 시에도 이런 질문을 배제하는 것이 서비스 품질·윤리 측면에서 바람직** (실제 면접에서도 금지되는 질문임을 콘텐츠로 안내 가능)
  - 채용서류 반환·파기 의무 → 우리 서비스의 "연습 기록 삭제권" 설계에 참고

## 4. 저작권·데이터

### 4-1. 복원 기출(면접 질문) 활용의 법적 성격

- **시험문제의 저작물성**: 판례는 출제자의 정신적 노력으로 만들어져 최소한의 창작성이 있으면 시험문제도 저작물로 보호(고교 중간·기말고사 문제, 대학 논술문제 인정 사례. 수능 문제로 평가원이 사용료를 받은 판결도 존재). 저작권법 제32조(시험문제로서의 복제)는 "시험을 위한 복제"를 면책할 뿐, **기출문제집 출판·영리 이용은 면책 대상 아님**.
- **그러나 면접 질문은 필기 문제와 다름**:
  - "우리 시의 현안과 해결 방안을 말해 보세요" 같은 **짧은 질문 문구는 창작성이 인정되기 어려움** — 판례는 제호·슬로건 등 간단하고 짧은 문구의 저작물성을 일관되게 부정(대법원 98도112 등).
  - "○○직 면접에서 이런 질문이 나왔다"는 것은 **사실(fact) 정보**이며 사실 자체는 저작권 보호 대상이 아님. 수험생 후기 기반 '복원'은 표현을 그대로 베끼는 것이 아니라 사실을 재구성하는 것이므로 침해 리스크가 낮음.
  - **국가·지자체가 업무상 작성하여 공표한 저작물은 공공저작물 자유이용(저작권법 제24조의2, 공공누리)** 대상 — 인사혁신처·지자체가 공식 공개한 면접 평정요소, 예시 질문, 안내자료는 자유 이용 가능(공공누리 유형 확인).
- **리스크 관리**: 타 학원·강사의 "복원 문제집"을 그대로 복제하는 것은 편집저작물 침해 소지 → 반드시 1차 출처(수험생 후기, 공식 자료)에서 독자적으로 수집·재작성.

### 4-2. 커뮤니티 게시글 인용 한계

- 커뮤니티 면접 후기 게시글은 그 자체로 **작성자의 어문저작물**일 수 있음(창작성 있는 서술 부분).
- 저작권법 제28조(공표된 저작물의 인용): 보도·비평·교육·연구 등 목적으로 정당한 범위 안에서 공정한 관행에 합치되게 인용 가능하되, **영리 목적은 허용 범위가 크게 좁아지고**, 인용이 주(主)가 되는 수집·전재는 인용으로 인정되지 않음. 출처 명시 의무 위반 시 500만원 이하 벌금.
- **안전한 실무**: ① 게시글 원문을 전재하지 말고 **질문이라는 사실 정보만 추출·재작성**, ② 서비스 내에 후기 원문을 노출해야 한다면 링크 방식 또는 작성자 동의, ③ 크롤링 시 해당 사이트 약관(무단 수집 금지 조항)·부정경쟁방지법(성과물 무단사용, 데이터 부정취득) 리스크 별도 검토 — 저작권과 별개로 **약관 위반·부정경쟁 책임**이 인정된 국내 판례 흐름 있음.

### 4-3. AI 학습 데이터 저작권 면책 (TDM) 입법 동향

- 한국 저작권법에는 **TDM(텍스트·데이터마이닝) 면책 조항이 아직 없음**. 도입 개정안(도종환안 등)이 수차례 발의됐으나 국회 통과 실패, 입법 지연 중.
- 해외: 영국(2014), 독일(2017), 일본(2018, 제30조의4 — 가장 넓음), EU DSM지침(2019) 등은 TDM 면책 입법 완료.
- 현재 국내에서 AI 학습의 적법성은 **제35조의5 공정이용 일반조항**으로 판단할 수밖에 없어 불확실성 존재. 문체부는 AI 학습데이터 **목록 공개(투명성) 의무**를 포함한 저작권법 개정 방향을 예고한 상태 → 동향 모니터링 필요.
- **우리 서비스 함의**: 타인 저작물(수험서, 강의 자료)을 학습·프롬프트 데이터로 대량 투입하는 것은 면책 근거가 불확실 → 공공저작물, 자체 제작 데이터, 이용자 동의 데이터 중심으로 데이터셋 구성 권장.

## 5. 전자상거래·이용약관 (유료화 시)

- **통신판매업 신고**: 유료 구독·결제 서비스는 전자상거래법상 통신판매업 신고 대상(정부24). 사업자등록 + 통신판매업 신고 필수. (부가통신사업 신고 여부도 규모에 따라 확인.)
- **신원정보 표시**: 사이트에 상호, 대표자, 주소, 전화번호, 이메일, 사업자등록번호, 통신판매업 신고번호, 이용약관 등 표시 의무.
- **청약철회(제17조)**: 계약 서면 수령일(서비스 개시일)부터 **7일 이내 청약철회 가능**이 원칙. 철회 시 **3영업일 이내 환급**.
  - **디지털콘텐츠 예외**: 제공이 개시된 디지털콘텐츠는 청약철회 제한 가능. 단, 제한하려면 **사전에 그 사실을 표시하고, 시용상품 제공·일부 이용 허용 등의 조치**를 해야 함. 분할 가능한 콘텐츠는 **제공이 개시되지 않은 부분에 대해서는 철회 가능** — 온라인 강의는 수강 기간이 아니라 "열람한 회차" 기준으로 환불액 산정해야 한다는 해석.
  - 구독형이면 언제든 해지 + 잔여기간 환불 기준을 약관에 명시(1개월 이상 계속거래는 방문판매법상 계속거래 해지권도 검토).
- **환불 규정 설계**: "AI 면접 1회 이용권"처럼 즉시 소비되는 상품은 사용 전 철회 가능/사용 후 철회 제한을 명확히 고지. 미사용분 환불 산식 명시.
- **참고 — 교육 규제**: 법제처 유권해석상 불특정 다수(성인 10명 이상)에게 유료 원격 교육을 하면 **평생교육법상 원격평생교육시설 신고** 대상이 될 수 있음(온라인 입시학원은 학원법이 아닌 평생교육법 적용). AI 자동 피드백만 제공하는 소프트웨어 서비스인지, '교습'에 해당하는 강의 콘텐츠를 파는지에 따라 달라지므로 유료 강의 콘텐츠 결합 시 관할 교육청 확인 필요.
- 약관은 약관규제법 적용: 고객에게 부당하게 불리한 조항(과도한 환불 제한 등)은 무효. 공정위 표준약관 참고.

## 6. 출시 전 법적 점검 체크리스트

### AI 기본법
- [ ] 생성형 AI 기반 서비스임을 약관·화면에 **사전 고지** (제31조)
- [ ] AI 생성 질문·피드백에 **"AI 생성" 표시** (서비스 내 제공 방식으로 유연 표시 가능)
- [ ] 고영향 AI 해당성 내부 검토 메모 작성 (연습 서비스로서 채용 '결정' 미수행 논거 문서화)
- [ ] 필요 시 과기정통부 **고영향 AI 확인** 신청 검토 (계도기간 내)
- [ ] 시행령·고시·가이드라인 업데이트 모니터링 담당 지정 (계도기간 종료 시점 확인)

### 개인정보보호법
- [ ] 개인정보 처리방침 작성·공개 (수집 항목: 음성/영상/텍스트 답변 명시)
- [ ] 수집·이용 동의 화면 (목적·항목·기간·거부권 고지), 녹음·녹화 시작 시점 인지 UX
- [ ] AI 학습(품질 개선) 목적 활용은 **별도 옵트인 동의** 또는 가명처리 절차 설계
- [ ] 얼굴·음성 **본인확인 기능 사용 여부 결정** → 사용 시 민감정보 별도 동의 + 암호화
- [ ] 해외 LLM API 사용 시 **국외 이전 항목을 처리방침에 공개** (이전받는 자·국가·항목·목적·기간), API 제공사 zero-retention 설정 확인
- [ ] 자동화된 처리(점수·피드백)의 기준·절차 공개 (제37조의2 대응, 신뢰 확보)
- [ ] 만 14세 이상 확인 절차 (미만 가입 차단)
- [ ] 보유기간 경과·회원 탈퇴 시 파기 절차, 연습 기록 삭제 기능
- [ ] 안전성 확보조치 (접근통제, 암호화, 접속기록) — 영상·음성은 유출 시 파급이 크므로 저장 최소화(분석 후 즉시 삭제 옵션) 검토

### 저작권·데이터
- [ ] 질문 데이터셋 출처 관리 대장 작성 (공공저작물/자체 제작/후기 기반 재작성 구분)
- [ ] 공공저작물은 공공누리 유형 확인, 출처 표시
- [ ] 커뮤니티 후기는 **원문 전재 금지, 사실 정보만 재작성**, 크롤링 대상 사이트 약관 확인
- [ ] 타사 복원 문제집·강의 자료 복제 금지 내부 지침
- [ ] TDM 면책 입법 및 문체부 저작권법 개정(학습데이터 공개 의무) 동향 모니터링

### 전자상거래·약관 (유료화 시)
- [ ] 사업자등록 + 통신판매업 신고
- [ ] 사이트 하단 사업자 신원정보 표시
- [ ] 이용약관·환불 규정: 7일 청약철회, 디지털콘텐츠 개시 시 철회 제한 사전 고지 + 미제공분 환불 산식, 3영업일 내 환급
- [ ] 구독 상품 해지·잔여기간 환불 정책, 결제 전 최종 확인 화면
- [ ] 유료 강의 콘텐츠 결합 시 원격평생교육시설 신고 필요성 확인

### 기타
- [ ] 채용절차법 개정(공정채용법, AI 채용 고지 의무) 입법 동향 모니터링
- [ ] 서비스 내 고지: "본 서비스는 연습용이며 실제 시험 결과와 무관" (기대 관리 + 표시광고법상 과장광고 방지)
- [ ] "합격 보장" 류 표현 금지 (표시광고법 부당 광고 리스크)

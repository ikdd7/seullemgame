# 7급 공무원 면접 (국가직·지방직·서울시)

> 수집일: 2026-07-04 / 출처: 응시자 복원 후기 및 공개 자료 기반
>
> ※ 인사혁신처·지자체는 7급 면접 과제(집단토의·개인발표 제시문)를 공식 공개하지 않는다. 아래 내용은 언론 기사(법률저널·고시위크 등)·수험가 공개자료·응시자 복원 후기에서 수집한 것으로, 실제 제시문과 표현이 다를 수 있다. 원문 커뮤니티 글(다음카페·디시인사이드 등)은 직접 열람이 제한되어 검색 결과 스니펫으로 확인한 내용임을 밝힌다.
> - [확인] : 출처 문서에서 내용이 직접 확인된 것
> - [복원참고] : 수험가에서 반복 언급되는 계열로, 원문 문구는 미확인

## 1. 9급 면접과의 차이 (구조 비교)

| 구분 | 9급 공채 | 국가직 7급 공채 |
|---|---|---|
| 총 면접시간 | 약 30분 내외 (개별면접만) | **약 120분** (집단토의 신설로 종전 70분 → 120분 확대) |
| 발표 | 5분발표 (제시문 10분 검토 → 5분 발표 + 후속질문 약 10분) | **개인발표(PT)** — 과제 작성 30분, 발표 + 후속질문 15분 |
| 토의 | 없음 | **집단토의** — 오전 진행, 과제 검토 약 10분 + 토의 50분 |
| 개별면접 | 경험·상황 면접과제(20분 작성) 기반 질의응답 | 경험·상황 과제 작성 20분 + 자기기술서·개별질문 25분 |
| 발표 성격 | 공직가치 유추형 (윤리·책임 검증 중심) | **정책보고서형** — 자료 요약, 문제점 분석, 정책대안 기획 |

- 국가직 7급 하루 일정(현행): **오전 집단토의 면접(50분, 주제 검토 10분)** → 점심 → **오후 개별면접**(경험·상황과제 작성 20분 → PT 과제 작성 30분 → PT발표·후속질문 15분 → 자기기술서·개별질문 25분). 면접위원은 응시자 1명당 3명 배치
- 집단토의 연혁: 2019년까지 시행(당시엔 찬반토론형 위주) → **코로나19로 2020~2023년 생략** → **2024년부터 재도입·확대**(면접시간 70분 → 120분). 재도입 첫해에는 기출 데이터가 없어 변별 포인트로 주목받음 [확인: 고시위크·나무위키]
- 평정요소: 2024.1.1.부터 9급과 동일하게 **소통·공감 / 헌신·열정 / 창의·혁신 / 윤리·책임** 4요소 (종전 5개 요소 폐지). 다만 7급은 집단토의·개인발표라는 기법으로 소통·공감(토의)과 창의·혁신(정책기획)을 더 무겁게 검증하는 구조
- 판정: 우수 / 보통 / 미흡 — 우수는 필기성적 무관 우선합격, 미흡은 탈락(9급과 동일한 방식)

## 2. 국가직 7급 개인발표(PT) — 형식과 기출

### 형식
- 특정 현안에 대한 **4페이지 전후의 자료(기사·통계·법령 등)** 를 30분간 검토하고 **21줄짜리 답안지에 수기로 요약·정리** → 상관에게 현안을 보고하듯 발표 → 후속 질의응답 [확인: 나무위키·수험가 자료]
- 평가 포인트: 데이터 요약·정리력, 현안의 주된 문제점 파악, 정책 기획의 방향성, 정책 창의력, 보고 논리력 — 9급 5분발표와 달리 **보고서 형식의 정형화된 틀**(현황–문제점–대안–기대효과)로 작성해야 한다는 후기가 다수

### 복원 기출 주제
- [확인] **2019 일반행정·우정**: "최근 이메일, 온라인 메신저, SNS 등을 통한 지속적 괴롭힘(사이버불링)이 발생하고 있다. 청소년 사이버불링의 현황과 문제점을 분석하고, 이를 해결하기 위한 바람직한 정책방안을 마련하시오" (법률저널 보도)
- [확인] **2019 인사·고용노동·교육행정·선거·관세·출입국·외무영사**: 어린이보호구역(스쿨존) 내 교통사고 관련 현황·대책 (법률저널 보도)
- [확인] **2010년대 중반(법률저널 "지난해" 보도분)**: ① 지방재정 안정화 방안 ② 고령화시대 독거노인 문제 해결 방안 ③ 근로장려금·자녀장려금 활성화 방안 ④ 쌀 시장 개방 및 쌀 관세화 찬반 논거 ⑤ (외국) 여행객 과소비 대응 방안
- [복원참고] 코로나 생략기 이후(2024~)에도 "사회현안 자료 제시 → 문제점 분석 → 정책대안 보고" 구조는 유지. 디지털 격차, 저출산·고령화, 청년정책, 탄소중립 등 범정부 현안 계열이 수험가 모의과제로 통용됨 (실제 제시문 문구는 미공개)

## 3. 국가직 7급 집단토의 — 형식과 기출

- 조별로 시험실 이동 후 **토의과제 검토시간 약 10분** 부여 → 면접위원의 지시에 따라 **자율 토의**(총 50분). 면접위원은 개입하지 않고 관찰 평가 [확인: 고시위크]
- [확인] 2019년(생략 전 마지막 시행)에는 **찬반토론형**으로 구성됐고, 당시 정부가 추진 중인 정책 관련 주제가 주를 이룸 (법률저널 보도)
- [확인] 과거 시행분에서는 "조원 간 의견을 나눈 후 **합의안을 도출**해야 했다"는 응시자 후기가 보도됨 — 단순 찬반 대립이 아니라 조정·합의 능력을 보는 방식
- [복원참고] 2024년 재도입 이후 주제는 응시자 복원이 커뮤니티(7급 공채 마이너 갤러리 등) 중심으로만 유통되며 공개 문서로는 미확인. 수험가에서는 정부 추진 정책의 쟁점형(규제 강화 vs 완화, 재원 배분 우선순위 등)을 표준 대비 유형으로 안내
- 평가 관전 포인트(수험가 공통 조언): 발언 횟수보다 **경청·요약·중재** — 사회자 역할 선점보다 타인 의견을 정리하고 합의점을 제시하는 발언이 고평가된다는 후기가 반복됨

## 4. 서울시 7급 면접

- 구조: 9급의 5분 스피치 대신 **PT발표(주제발표)** + 개별 인성·직무 면접. 발표 후 후속질문이 이어지는 방식 [확인: 나무위키·응시자 후기]
- [확인] 복원 기출(응시자 후기): **"디지털 소외계층과 그로 인한 세대 간 갈등을 해결할 수 있는 구체적 방안"** PT 발표
  - 후속질문: ① 본인이 겪었던 갈등 상황이 있는지, 있으면 설명 ② 조직이 추구하는 방향과 내가 추구하는 방향이 다르면 어떻게 할 것인지(본인 경험 포함) ③ 조직이 잘못된 방향으로 가는데도 조직을 따를 것인가
- 서울시 특성: 서울시정 현안(약자와의 동행, 디지털 격차, 주택·교통 등)과 연결한 발표·질문 비중이 높다는 후기 다수 [복원참고]
- 준비 팁(합격 후기): 발표는 4분 이상 채우는 연습 필수, 영상 촬영으로 시간 감각 훈련, 아이컨택·표정·예의 등 태도 요소가 당락에 크게 작용

## 5. 지방직 7급 면접 (시·도별)

- 시·도별로 방식이 다르나 공통적으로 9급 대비 **주제발표(개인발표)** 가 추가되는 구조. 집단토론을 두는 지자체도 있었으나 코로나 이후 상당수 생략 [확인: 나무위키]
- **사전조사서**: 경기·충북·대구 등 다수 지자체가 면접 전 사전조사서(자기기술서 유사)를 작성하게 하고 이를 기반으로 개별질문 진행 [확인: 수험가 공개양식]
- 복원 기출(개별질문 계열):
  - [확인] 충청북도: 충북도가 추진하는 정책들을 아는 대로 말해보라
  - [확인] 충청남도: 충남 남부 지역과 관련해 추진할 정책과 전략을 제시할 수 있는가
  - [복원참고] 공통 빈출: 해당 지역 현안·인구감소 대응·지역 축제/브랜드 정책, 전공과 직무 연결, 한계에 부딪힌 경험, 공무원의 봉사정신이 필요한 이유
- 경기도 특성: "지방직 면접은 미흡이 드물다"는 속설이 경기도에는 적용되지 않으며, 우수보다 미흡이 더 많았던 해가 있다는 후기 — 상대적으로 엄격한 평가 기조 [확인: 응시자 후기 스니펫]

## 6. 7급 특화 평가 포인트

1. **정책기획·보고 역량**: 개인발표가 '공직가치 유추'(9급)가 아니라 '현안 보고서 작성·보고'라는 점이 최대 차이. 현황–문제점–대안(단기/중장기)–기대효과·한계 틀을 체화해야 함
2. **협업·조정 능력(집단토의)**: 소통·공감 요소의 주검증 기법. 독주형 발언, 타인 발언 무시가 감점 요인으로 반복 언급됨. 합의안 도출 요구에 대비해 중재·요약 발언 연습 필요
3. **중간관리자 예비군 관점**: 7급은 실무 총괄·기획 보조 역할이 기대되므로 리더십·업무 우선순위 판단·이해관계 조정 질문이 개별면접에서 비중 있게 나옴 [복원참고]
4. **후속질문 대응력**: 발표 내용의 재원, 실현 가능성, 부처 간 협업, 반대 이해관계자 설득 방안을 파고드는 후속질문이 많아 발표문 자체보다 질의응답에서 변별된다는 후기 다수
5. **자기기술서 기반 심층 개별면접**: 경험·상황 과제(20분 작성)에 대해 25분간 파고드는 구조로, 9급보다 검증 시간이 길고 집요함

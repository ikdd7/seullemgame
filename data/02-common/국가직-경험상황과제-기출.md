## 1. 과제 형식 개요 (9급)

- 면접 당일 대기장에서 **경험형 과제 + 상황형 과제를 합쳐 20분간 작성** (각 과제 최대 12줄, 자료 참고 불가)
- 작성한 과제지를 바탕으로 면접 후반부 **약 20분간 심층 질의응답** (5분발표+후속질문 10분에 이어 진행, 총 30분 내외)
- **경험형**: 전 직렬 동일 문제이며 문항이 시험 공고문에 사전 공개됨
- **상황형**: 직렬(직류)별로 다른 제시문이 당일 공개됨. 특정 상황에서의 판단을 묻고 **문제해결능력·상황판단·공직가치 기반 윤리적 판단**을 평가
- 2024년까지 감압지(볼펜 꾹꾹, 수정테이프 불가) 방식 → **2025년부터 A4 작성 후 복사 제공 방식으로 변경**
- 답안 정석 구조: 상황 요약 → 나의 판단(결론) → 근거 → 예상 문제점(장단점) → 보완책

## 2. 경험형 과제 기출 문항 (전 직렬 공통)

- [확인] 2019~2025 공통 정형 문항: **"임용 이후 근무하고 싶은 부처(기관)와 담당하고 싶은 직무(정책)를 기술하고, 해당 분야의 직무수행능력·전문성 함양을 위해 기울인 노력과 경험을 서술하시오."**
  - 후속질문 빈출: 해당 부처의 관련 정책 이해도, 노력·경험의 구체성 검증, 직무에 적용 방안
- [확인] 경험형은 2024년 기준으로도 전 직렬 동일 출제 + 공고문 사전 공개 방식 유지
- 후속 개별질문 빈출(경험형 연계): 지원동기, 직렬 관련 법·제도 기초(세무직: 국세기본법 정의 등), 갈등 해결 경험, 다양성 발휘 경험, 헌신·봉사 경험

## 3. 상황형 과제 기출 (연도별·직렬별)

### 2018년
- [복원참고] 상사의 부당·위법 지시 상황, 규정과 민원인 요구 충돌 상황 등 고전형 딜레마가 주류였다는 후기 (교정직 복기에서는 상황형보다 직렬 전문질문 비중이 컸다고 전함)

### 2019년
- [복원참고] (세무직) 체납·부과 업무에서 규정 적용과 납세자 사정이 충돌하는 상황 계열 — 쟁점: **합법성 vs 형평성·적극행정**. 세무직 합격 후기 공통 조언: "상황과제는 기출만 해도 충분하다"
- [확인] (고전 기출, 2015 전산직) 상사가 시스템에 무단 접근한 사실을 알게 됐다면? — 쟁점: **조직 내 위법행위 보고 vs 상하관계** (유형 참고용)

### 2020년
- [복원참고] 코로나19 상황을 반영한 민원 폭증·비대면 행정 상황 계열 — 쟁점: **행정 효율 vs 취약계층 접근성** (고용노동직 복기 존재하나 원문 열람 제한)

### 2021년
- [확인] (일반행정) **무인민원발급기 설치 여부 판단**: 설치 시 장점(민원 대기시간 단축, 만족도 향상, 행정 효율성 증대)과 단점(해당 지역 민원업무량 부족, 예산 비효율, 고령자 안내 인력 필요)이 제시된 상황에서 담당자로서의 판단 — 쟁점: **예산 효율성 vs 주민 편의·디지털 소외**

### 2022년
- [확인] (일반행정) **공익근무요원 무단 아르바이트 처벌 딜레마**: 관리담당자로서 허가받지 않은 아르바이트를 한 공익요원을 규정상 처벌해야 하는데, 본인은 생계곤란을 주장하고, 조사 결과 '아주 곤란하지는 않지만 어려움은 있는' 상태로 확인된 상황 — 쟁점: **규정 준수(공정성) vs 인도적 배려(적극행정·재량)**
- [확인] (6.11. 오전조) **초과근무·수당 허위 기재 감사 상황**: 감사 결과 직원 약 120명의 초과근무 허위 기록이 적발된 조직 상황에서의 대응 — 쟁점: **조직 관행 vs 청렴·책임, 내부통제 개선** (해당 후기에서는 5분발표 제시문과 연계 출제로 복원됨)

### 2023년
- [복원참고] 평정요소 개정(소통·공감/헌신·열정/창의·혁신/윤리·책임) 첫 적용 연도. 민원 갈등 조정형·업무 우선순위 충돌형(기한 임박 업무 vs 긴급 민원) 시나리오가 후기에서 언급 — 쟁점: **소통·공감 역량 검증 강화**
- [확인] 합격생 조언(카페 모음글): 상황형은 "정책·사건 사례를 미리 분류해 두고 판단 근거로 활용"하는 방식이 유효

### 2024년
- [복원참고] 직렬별 상황형 유지(세무 5.29, 고용노동 5.31, 관세 6.3 등 직렬별 일자 분리 시행). 악성·특이민원 대응, 적극행정 면책 판단, 부처 간 협업 갈등 계열 시나리오가 학원 복원 대상 — 쟁점: **민원인 보호 vs 공무원 보호, 소극행정 탈피**
- [확인] 경험형 과제 작성법 안내(공기출 게시판)에서 2024년도 동일 형식 확인

### 2025년
- [복원참고] 면접 5.28~6.2 시행. A4 작성 방식 첫 적용 외 과제 구조 동일. 세무직 최종합격 후기(스티마 카페) 존재 확인되나 원문 열람 제한 — 상황형은 기존 기출 변형(규정 vs 재량, 예산 vs 형평) 범주였다는 평
- [확인] 2025년부터 상황형·경험형 과제 작성이 A4 + 복사 제공 방식으로 개선(나무위키 확인)

### 상황형 빈출 딜레마 유형 (기출 질문 모음에서 확인)
- [확인] 상사가 부당한 지시를 한다면? / 상사의 지시가 위법하다면? — **복종의무 vs 법령준수**
- [확인] 민원인이 법에 어긋난 것을 요청한다면? — **친절·봉사 vs 합법성**
- [확인] 조직의 요구와 개인의 가치관이 충돌하면 어느 쪽이 우선인가? — **조직몰입 vs 소신**
- [복원참고] 예산 부족 속 사업 우선순위 결정형 / 신구 세대 조직문화 갈등형 / 규정 공백 상태에서의 적극행정 판단형

## 4. 국가직 7급 집단토의 (+개인면접 과제)

### 연혁·형식
- [확인] 집단토의는 5급 면접과 유사한 방식으로 7급에 도입(도입 당시 "기출 데이터 없음"이 언론에서 화제). **2020·2021년은 코로나19로 집단토의 전면 생략**, 이후 재개
- [확인] 현행: 오전 **집단토의 면접 50분(주제 검토 10분 포함)**, 오후 개별면접(경험·상황과제 작성 20분 → PT 과제 작성 30분 → PT 발표+후속질문 15분 → 자기기술서·개별질문 25분)
- [확인] 집단토의 형식 변화: 초기에는 조원 간 의견 교환 중심 → 이후 **조원 의견 교환 후 합의안 도출**을 요구하는 방식으로 강화
- 7급도 경험·상황형 과제(자기기술서 포함)를 작성하며, 9급과 같은 딜레마형 상황 판단이 출제됨

### 확인된 토의·발표 주제
- [확인] **자유학기제** (일반행정 집단토의) — 쟁점: 교육정책의 실효성, 부처 협업
- [확인] **통일비용 마련 방안** (일반행정 개인발표) — 쟁점: 재원 조달, 세대 간 부담
- [확인] (집단토의 도입 직전 연도 개인발표, 유형 참고) 지방재정 안정화 / 독거노인 문제 / 근로장려금·자녀장려금 활성화 / 쌀 관세화 찬반 / 여행객 과소비 대응
- [복원참고] 재개(2022~) 이후 집단토의는 찬반 대립형보다 **정책 대안 합의 도출형**(인구·지역소멸, 디지털 행정, 청년 정책 등 범부처 현안)이 주류라는 수험가 평. 연도별 원문 복원은 공개 자료에서 확인 불가 — 커뮤니티(피티윤 카페 '국가직 7급 면접 대비' 게시판 등) 원문 참조 필요

## 5. 준비 포인트 요약

1. 상황형은 **"결론 유보 없이 판단 + 근거 + 보완책"** 구조가 핵심. 규정 우선을 원칙으로 하되 재량·적극행정 여지를 보완책으로 배치
2. 경험형은 문항이 공고문에 공개되므로 **부처·정책 지정 + 노력·경험 매칭**을 사전에 완성해 12줄 분량으로 암기
3. 두 과제 모두 오픈북이 아니므로 자료 없이 20분 내 작성하는 연습 필수
4. 직렬별 상황형은 해당 직렬의 실무 딜레마(세무: 체납·부과, 고용노동: 사업주-근로자, 관세: 통관-단속)로 출제되므로 직렬 기출 우선 학습

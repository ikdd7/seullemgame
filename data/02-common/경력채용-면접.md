> 수집일: 2026-07-04 / 출처: 응시자 복원 후기 및 공개 자료 기반
>
> ※ 경채 면접은 시험(민경채·지역인재·부처 상시채용·지방 경채)마다 주관 기관과 방식이 달라 공채처럼 단일 표준이 없다. 아래 내용은 인사혁신처 공고·언론 기사·수험가 공개자료·응시자 복원 후기에서 수집한 것으로, 실제 과제·질문과 표현이 다를 수 있다. 커뮤니티 원문은 직접 열람이 제한되어 검색 결과 스니펫으로 확인했다.

> - [복원참고] : 수험가에서 반복 언급되는 계열로, 원문 문구는 미확인

## 1. 경채 개요와 유형

경력경쟁채용은 "경력 등 응시요건을 정하여 같은 사유에 해당하는 다수인을 대상으로 경쟁의 방법으로 채용하는 시험"으로, 공채로 충원이 곤란한 분야의 전문인력·유경력자를 뽑는 제도다. [확인: 인사혁신처]

| 유형 | 대상/요건 | 절차 |
|---|---|---|
| **민간경력자 일괄채용(민경채) 5·7급** | 민간 경력·학위·자격증 요건 충족자 | PSAT 필기 → 서류전형 → 면접 |
| **지역인재 7급 수습직원** | 대학 추천 (학과 성적 등) | PSAT 필기 → 서류 → 면접 → 수습 후 임용 |
| **지역인재 9급 수습직원** | 특성화고·마이스터고 등 추천 | 필기 → 면접(면접 100% 평가) → 수습 후 임용 |
| **부처별 상시 경채(국가직)** | 직위별 자격증·경력 (나라일터 공고) | 서류 → (필기/실기) → 면접, 기관별 자율 |
| **지방직 경채(기술·간호·사회복지·운전 등)** | 자격증 소지 등 | 필기(과목 축소) 또는 서류 → 면접 |

- 공통점: 필기 비중이 낮거나 없는 대신 **서류(경력·직무수행계획서)와 면접에서 직무 적격성을 검증**하는 구조

## 2. 민간경력자 일괄채용(민경채) 면접

### 형식 [확인: 인사혁신처 공고·수험가 안내]
- 면접위원: **5급 5인 1조, 7급 4인 1조** / 면접시간: **5급 약 50분, 7급 약 35분** (개인발표 + 경험·상황 과제 기반 질의응답)
- 사전 작성: 진행요령 안내(15~20분) 후 **면접시험 평정표(5급 4매, 7급 3매)·경험·상황 면접과제·개인발표과제** 작성
- 개인발표: 당일 별도 공간에서 **하나의 주제에 대해 A4 4~5장 분량의 기사·통계 자료** 제공 → **A4 1장 분량 발표문을 수기 작성** → 면접위원 앞 발표. 현안 보고서를 신속히 작성해 상관에게 보고하는 실무 능력을 평가
- 7급 면접 구성 복원 후기: 개인발표면접 20분 + 자기기술서 기반 개별면접 20분 (총 40분 내외)

### 복원 기출
- [확인] 개인발표: **청소년 비속어 사용 원인 및 개선방안**, **중국 관광객 유치방안** (7급 민경채, 법률저널 계열 보도)
- [확인] 개별면접: 지원동기 / 공무원으로서 민원인 처리 방법 / **다니던 직장에서 업무가 힘들었던 경험과 극복 노력** / 공무원 갈등해결 방안 / 공무원과 봉사
- [복원참고] 경력 검증 계열: 경력기술서에 쓴 프로젝트의 본인 기여도, 민간 경력을 해당 직위에 어떻게 접목할 것인가, 공직과 민간의 일하는 방식 차이

## 3. 지역인재 7급 수습직원 면접

- 구성: **개인발표 + 경험 과제 + 상황 과제** (작성은 경험→상황→개인발표 순, 실제 면접은 개인발표→경험→상황 순) [확인: 나무위키]
- 개인발표: **4페이지 전후의 자료**를 주고 발표능력을 기본으로 **데이터 요약·정리, 현안의 문제점 파악, 정책 기획 방향성, 정책 창의력**을 종합 평가 — 국가직 7급 공채 PT와 같은 보고서형
- 사전조사서 취급 차이: 개인발표 과제 작성본은 **복사 후 원본을 응시자에게 돌려주지만**, 경험·상황 과제 작성본은 **수거되어 응시자는 기억에 의존해 답변**해야 함 [확인]
- 경험 과제: 조직 생활 중 갈등 상황 대처 경험(과거 기반 인성 검증) / 상황 과제: 미래 가정형 인성 검증
- [확인: 합격 후기] 학원 표준 준비(자기소개·클로징 멘트·장단점·희망부처)를 전혀 묻지 않은 사례도 있음 — 과제·발표 기반 검증 비중이 큼

## 4. 지역인재 9급 수습직원 면접

- **필기 성적과 관계없이 면접 100%로 평가** [확인: 나무위키]
- 면접 약 30분: **5분 스피치 포함** + 자기기술서 기반 질문 + 전문지식 등 기타 질문
- 평정요소(복원 당시 기준): 공직 자세 / 전문지식 / 의사표현·논리성 / 예의·품행 / 창의력·발전가능성 5개 요소 상·중·하 평정 — ※ 2024년 이후 국가직 공통 4요소(소통·공감, 헌신·열정, 창의·혁신, 윤리·책임) 개편이 적용되므로 최신 공고 확인 필요 [복원참고]
- 고졸(특성화고·마이스터고) 추천 채용 특성상 학교생활·직업윤리·성실성 검증 질문 비중이 높다는 후기 [복원참고]
- 최종합격 후 국가공무원인재개발원 연수(3~4주) → 부처 배치 6개월 수습 → 평가 후 임용

## 5. 직무수행계획서 기반 면접 (상시 경채·임기제·지방 경채)

- 직무수행계획서: 해당 직위 담당자로서 **향후 직무를 어떻게 수행할지에 대한 계획 문서**. 경채(특히 임기제·연구직·개방형 직위)에서 응시원서와 함께 제출하며 면접의 중심 자료가 됨 [확인]
- 표준 구조: **서론(직무에 대한 이해) → 본론(상황분석에 따른 직무 계획안) → 결론(직무 수행 방안·기대효과)**
- 면접 활용 방식: 계획서 요지 발표(3~5분) 후 면접위원이 계획의 실현 가능성·재원·법적 근거·기관 현안 접목을 검증하는 질의응답 [복원참고]
- 빈출 검증 포인트: 기관의 최근 업무계획·현안을 계획서에 반영했는가, 목표가 측정 가능한가, 본인 경력과 계획의 연결 고리가 구체적인가

## 6. 기술 경채 복원 기출 (전산·간호·운전 등)

### 전산직 [확인: 응시자 후기(브런치·복원 게시판)]
- 전산직 공무원의 업무가 무엇이라고 생각하는가 (전산 예산 관리, 서버·시스템·운영 프로그램 관리 등)
- 기술 트렌드가 계속 바뀌는데 전산직으로서 어떻게 계속 공부할 것인가
- **DDoS 공격을 피하려면 어떤 식으로 운영해야 하는가** (전공 심층)
- [복원참고] 정보처리기사 등 응시 요건 자격증 관련: 자격증 취득 과정에서 배운 것, 보안사고 대응 절차, 개인정보보호 법령 상식

### 간호직(8급 경채 포함) [복원참고: 간호사 면접 자료·후기 종합]
- 임상 경력 검증: 병원에서의 근무 부서·업무, 힘들었던 케이스와 대처
- 지역사회간호·보건소 업무 이해: 방문간호, 감염병 대응, 만성질환 관리 사업
- 인성: 생활신념, 바람직한 간호사(공직 간호인력)상, 민원인(주민) 응대

### 운전직·기타 지방 경채
- [확인] 울릉군 운전직(2021): "울릉군의 2021년 군정 방향에 대해 말해보라" — 기술직이라도 지역 현안 질문이 나옴
- [복원참고] 사회복지 경채: 전공(사회복지)과 담당 업무의 연결, 복지 사각지대 발굴 방안, 악성 민원 대처

## 7. 경채 빈출 공통 질문 (경력·이직 검증)

1. **왜 이전 직장을 그만두었는가** — 경채 면접 최빈출. 전 직장·동료에 대한 부정적 언급은 감점 요인이라는 조언이 정형화되어 있음 [확인]
2. **왜 퇴직 후 ○○직(공무원)에 지원했는가** — 민간 대비 보수 하락 감수 여부, 공직 가치관 검증
3. 전 직장에서 낸 성과와 본인 기여도 (경력기술서 대조 검증)
4. 민간 경력을 이 직위에서 어떻게 활용할 것인가 (조직 기여도)
5. 업무가 힘들었던 경험과 극복 노력 [확인: 민경채 기출]
6. 상사와 의견이 다를 때 / 조직 문화가 맞지 않을 때 어떻게 할 것인가 (조직 적응력 — 이직자에게 특히 집요하게 확인)
7. 공직과 민간의 차이가 무엇이라고 생각하는가 / 공무원의 봉사정신이 왜 필요한가

## 8. 9급 공채 면접과의 차이점

| 구분 | 9급 공채 면접 | 경채 면접 |
|---|---|---|
| 표준화 | 인사혁신처 단일 표준 (5분발표 + 경험·상황 개별면접, 약 30분) | 시험·기관별 상이 (민경채는 인사혁신처 표준, 상시·지방 경채는 기관 자율) |
| 검증 축 | 공직가치·인성 중심 | **경력·전공·직무 적격성** 중심 + 공직가치 |
| 사전 제출물 | 없음 (당일 과제 작성) | 경력기술서·자기소개서·**직무수행계획서** 등 서류가 면접 자료로 활용 |
| 발표 | 5분발표(공직가치 유추형) | 민경채·지역인재 7급은 보고서형 개인발표, 상시 경채는 발표 생략 또는 계획서 발표 |
| 빈출 질문 | 공직가치, 갈등 경험, 상황 대처 | 위 + **이직 사유, 전 직장 경험, 경력-직무 연결** |
| 평정·판정 | 4요소(소통·공감 등), 우수/보통/미흡 | 민경채·지역인재는 공채와 같은 평정 체계, 기관 자율 경채는 5요소 상·중·하 등 공고별 상이 |
| 유의점 | 필기 성적이 '보통' 판정 시 반영 | 필기 비중이 없거나 낮아 **면접 비중이 사실상 절대적** (지역인재 9급은 면접 100%) |

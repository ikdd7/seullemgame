# AI 모의면접 세션 설계 — 세션 흐름·상태 머신·질문 선택

> 작성일: 2026-07-05

공무원 AI 면접 시스템의 모의면접 세션 엔진 설계 문서.
근거 자료: `data/01-evaluation-criteria/national.md`, `local.md`(면접 방식·평정 규칙),
`data/03-regions/*.md`(지자체별 방식), `data/06-answer-guides/평가루브릭-설계.md`(채점 파이프라인),
`data/07-structured/questions.json`(질문 풀 1,941건).

## 1. 실제 면접 재현 시나리오

세션은 "면접 트랙(track)"을 먼저 선택한다. 트랙은 **국가직 9급형 / 지방직 표준형 / 지자체 변형** 3계열로 나누고, 지자체 변형은 지역 선택 시 자동 매핑한다.

### 1-1. 국가직 9급형 (`track: national-9`)

실제 시험(응시자 1인당 총 30분 내외 + 과제 작성 20분)을 다음 5단계로 재현한다.

| 단계 | 실제 제도 | AI 재현 방식 | 시간 |
|---|---|---|---|
| ① 경험·상황 과제 작성 | 대기장에서 경험형 1 + 상황형 1 작성(각 최대 12줄) | 텍스트 입력 폼 2개 제공. 경험형은 "근무 희망 부처·직무 + 필요 역량 + 관련 경험", 상황형은 questions.json의 `type=상황형` 과제형 제시문 1건 출제. 12줄(약 600자) 입력 제한 | 20분 |
| ② 5분 발표 제시문 검토 | 시험 당일 제시문 검토 | 공직가치·적극행정·정책 사례 제시문 1건 제시(`type=발표` 또는 LLM 생성), 메모장 제공 | 10분 |
| ③ 5분 발표 | 5분 내외 발표 | 음성 녹음(STT). 4:30 경과 시 잔여시간 표시, 5:30 강제 종료 | 5분 |
| ④ 발표 후속 질의 | 후속질문 10분 내외 | 발표 전사문 기반 꼬리질문 2~4개 생성(윤리의식·책임성 등 공직가치 검증 관점) | 10분 |
| ⑤ 경험·상황 심층면접 | 작성 과제 기반 20분 질의 | ①의 작성문을 컨텍스트로 심층 질문. 경험형 → STAR 검증, 상황형 → 판단 근거·대안·보완책 추궁 | 20분 |

- 면접위원: 2인 시뮬레이션(과반수 = 2인 일치). 평정요소는 4대 요소(소통·공감/헌신·열정/창의·혁신/윤리·책임).
- 지역현안 질문은 출제하지 않음(국가직 특성). 대신 "근무 희망 부처" 관련 직무 질문으로 대체.

### 1-2. 지방직 표준형 (`track: local-standard`)

사전 산출물(사전조사서 또는 스피치) + 개별면접의 2단계 구조. 지역 선택이 없는 기본값.

| 단계 | AI 재현 방식 | 시간 |
|---|---|---|
| ① 사전조사서 작성 | 지역·시사 주제 1건에 대한 짧은 글 작성(경기·충북·대구형). 작성 내용은 이후 추적 질문의 컨텍스트가 됨 | 10분 |
| ② 개별면접 | 공직가치·인성·직무·지역현안·상황형 질문 믹스(§3의 쿼터 샘플링). 사전조사서 기반 추적 질문 1~2개 포함 | 15~25분 |

- 면접위원: 2~3인. 국가직 대비 **지역현안 비중을 높인다**(local.md: 지역 현안·시정 질문이 비중 있게 출제).

### 1-3. 지자체 변형 (지역 선택 시 자동 적용)

수집 자료(03-regions) 기반 변형 프로파일. `region_profile` 테이블로 관리한다.

| 지역 | 변형 내용 | 세션 구성 |
|---|---|---|
| **서울특별시** | 5분 스피치 + 개별면접. 사전조사서 없음. 스피치 주제는 인성·시정·시사 골고루(예측 어려움) | 스피치 검토 10분 → 5분 스피치 → 스피치 후속질의 → 개별면접 20~25분. 지역현안은 퀴즈식 대신 정책 견해형 위주, 기초 시정 상식(시조·시화·시목, 인구·예산) 1문 허용 |
| **부산광역시** | 자기소개 → 3분 스피치(준비 10분) → 개별면접 약 15분. 발표 시간 제한 느슨, 압박 강도 낮음 | 스피치 준비 10분 → 자기소개(1분) → 3분 스피치(제한 3~5분, 강제 종료 없음) → 개별면접 15분. 기본 난이도를 '온화'로 설정 |
| **대구광역시** | 사전조사서 작성 + 개별면접, **위원 3인(친절 1·보통 1·압박 1)**. 지역 질문 비중 높음 | 사전조사서 10분 → 개별면접 15~20분. 3인 페르소나 활성화, 지역현안 쿼터 +1 |
| **인천광역시** | 집단토론(2023~) + 개별면접 | 집단토론은 1인 서비스 특성상 **모의 토론 모드**로 재현: AI 가상 토론자 2인이 상반된 입장 제시 → 사용자 입장 발표(2분) → 반론 대응 2회. 이후 개별면접. 평가에 경청·조정 지표 가중 |
| **경기도** | 사전조사서(일부 시·군) + 개별면접. '미흡' 비율 높다는 후기 → 검증성 질문 강도 높음 | 지방직 표준형 + 실전 모드 기본값. 답변-과제 일관성 검증 질문 강화 |
| 기타 광역 | 프로파일 미보유 시 지방직 표준형으로 폴백 | — |

> 유의: 지자체 방식은 연도별로 변한다(부산·대구 평정요소 개편 등). `region_profile`에 `verified_year` 필드를 두고, 세션 시작 화면에 "응시 연도 공고문 확인 필요" 고지를 노출한다.

## 2. 세션 상태 머신

### 2-1. 상태 정의와 전환

```
INTAKE ─→ [PREWORK] ─→ [SPEECH_PREP → SPEECH → SPEECH_QA] ─→ INTERVIEW ─→ WRAPUP ─→ SCORING ─→ FEEDBACK
   │                                                             │
   └──────────── 트랙에 없는 단계는 건너뜀 ─────────────────────────┘
INTERVIEW 내부:  ASK → LISTEN → (FOLLOWUP ↺ depth≤max) → NEXT_QUESTION
```

| 상태 | 내용 | 시간 제한 | 전환 조건 |
|---|---|---|---|
| `INTAKE` | 트랙·지역·직렬·난이도 선택, 마이크 점검 | 없음 | 사용자 시작 |
| `PREWORK` | 경험·상황 과제(국가직) / 사전조사서(지방직) 작성 | 국가직 20분 / 지방직 10분 | 제출 or 시간 만료(작성분 자동 제출) |
| `SPEECH_PREP` | 발표·스피치 제시문 검토, 메모 작성 | 10분 | 시간 만료 or "준비 완료" |
| `SPEECH` | 발표 (국가직 5분 / 서울 5분 / 부산 3분) | 목표시간 +30초에 소프트 컷, +60초 하드 컷(부산은 하드 컷 없음) | 발화 종료 감지(3초 무음 + 종결어) or 컷 |
| `SPEECH_QA` | 발표 후속 질의 | 국가직 10분 / 지방직 5분 | 후속질문 소진 or 시간 만료 |
| `INTERVIEW` | 개별면접 본체(질문 큐 순회) | 트랙별 15~25분 | 질문 큐 소진 or 시간 만료 |
| `WRAPUP` | "마지막으로 하고 싶은 말" 1문 | 1분 | 답변 종료 |
| `SCORING` | 루브릭 파이프라인 실행(평가루브릭-설계.md §4-3) | — | 채점 완료 |
| `FEEDBACK` | 등급 + 요소별 근거 + 스피치 코칭 + 예상 꼬리질문 제시 | — | 종료 |

세션 공통 규칙:
- 모든 상태 전환 시 `session_log`에 타임스탬프·전사문·질문 ID를 기록(채점 시 이전 답변 대조 = 일관성 red flag 탐지에 사용).
- 개별 답변의 목표 길이 30초~1분. 15초 미만 답변에는 1회 자동 재질문("조금 더 구체적으로 말씀해 주시겠습니까?"), 2분 초과 시 소프트 컷.
- 질문 후 10초 무응답 → "천천히 생각하고 답하셔도 됩니다" 프롬프트, 30초 무응답 → 해당 질문 skip 처리(무응답은 미흡 판정 최다 원인이므로 피드백에서 강한 경고).

### 2-2. INTERVIEW 내부 루프와 꼬리질문 트리거

```
ASK(main_q) → LISTEN(STT) → analyze(answer)
  ├─ trigger 감지 & depth < max_depth → FOLLOWUP(생성 질문) → LISTEN → analyze …
  └─ trigger 없음 or depth == max_depth → NEXT_QUESTION
```

꼬리질문 트리거 규칙 (답변 전사문을 경량 LLM 분석 1회로 판정, 우선순위순):

| # | 트리거 | 감지 신호(키워드/패턴) | 꼬리질문 방향 | 최대 뎁스 |
|---|---|---|---|---|
| T1 | **red flag** | 규정 무시·사익 우선·책임 전가·집단 비하·부정적 공직관 (루브릭 §4-2 red flag 목록) | 재확인·소명 기회 1회 ("방금 ~라고 하셨는데, 그렇게 판단한 근거는?") | 1 |
| T2 | **진술 모순** | 서면 과제·이전 답변과 불일치(세션 로그 대조) | 압박형 대질 ("아까는 ~라고 하셨습니다. 어느 쪽입니까?") | 2 |
| T3 | **경험 주장** | "~한 경험이 있습니다", "~했었습니다", 과제 작성문의 경험 서술 | STAR 검증: 상황→본인 역할→행동→결과→배운 점 순으로 파고들기 | 3 |
| T4 | **추상어·선언** | "소통하겠습니다", "노력", "열심히", "최선을 다해" 등 구체 행동 없는 선언 | 구체화 요구 ("구체적으로 어떤 방법으로?") | 2 |
| T5 | **정책·수치 언급** | 정책명·사업명·수치 인용 (예: "기후동행카드", "재정자립도") | 지식 검증 ("그 정책의 한계나 보완점은?") — 지역 컨텍스트 데이터와 대조 | 2 |
| T6 | **원칙 답변(상황형)** | 상황형에서 교과서식 답변 ("법령에 따라 처리하겠습니다") | 조건 변경 압박 ("그런데 상사가 그래도 하라고 하면?", "민원인이 언론에 제보하겠다고 하면?") | 3 |
| T7 | **미완결 답변** | 15초 미만, 결론 없는 종료, "잘 모르겠습니다" | 유도 재질문 1회 후 통과 (압박 아님, 코칭 대상 기록) | 1 |

- 뎁스 카운트는 주질문 단위로 리셋. 동시 다중 트리거 시 우선순위(T1>T2>…)가 높은 것 하나만 실행.
- 세션 전체 꼬리질문 예산: 총 면접시간의 40%를 넘지 않도록 잔여 시간 기반으로 `max_depth`를 동적으로 하향(시간 부족 시 T3~T6 뎁스를 1로 강제).
- 꼬리질문은 questions.json의 `type=후속` 항목을 우선 검색하고, 매칭이 없으면 LLM 생성(질문생성-프롬프트-템플릿.md §4 템플릿 사용).

## 3. 질문 선택 알고리즘

### 3-1. 입력과 필터

```
입력: region(지자체), job(직렬), track, difficulty, n_questions(기본 10)
질문 풀: data/07-structured/questions.json (1,941건)
```

1. **후보 필터링** (완화 단계적 적용 — 좁은 조건부터 시도, 부족하면 넓힘):
   - 1순위: `region == 선택지역 AND job == 선택직렬`
   - 2순위: `region == 선택지역 AND job == null` + `job == 선택직렬 AND region == null`
   - 3순위: `category == common` (지역·직렬 무관 공통)
   - 국가직 트랙은 `region != null` 항목 전체 제외.
2. **중복 제거**: 텍스트 임베딩 유사도 0.9 이상 쌍은 `reliability` 우선순위가 높은 쪽만 유지(README 한계 항목 반영).

### 3-2. 유형 쿼터 샘플링

개별면접 10문 기준 기본 쿼터(지방직 표준형):

```
공직가치 2 + 인성 2 + 직무 3 + 지역현안 2 + 상황형 1  = 10
```

트랙·지자체별 쿼터 조정:

| 트랙/지역 | 공직가치 | 인성 | 직무 | 지역현안 | 상황형 | 비고 |
|---|---|---|---|---|---|---|
| 국가직 9급형 (⑤단계) | 2 | 2 | 3 | 0 | 3 | 상황형은 작성 과제 연계분 포함. 지역현안 → 부처·직무 질문으로 치환 |
| 지방직 표준형 | 2 | 2 | 3 | 2 | 1 | 기본값 |
| 서울특별시 | 2 | 3 | 3 | 1 | 1 | 퀴즈식 지역질문 지양, 시정 상식 1문까지 |
| 대구·경북 등 지역질문 강세 | 2 | 1 | 3 | 3 | 1 | 지역현안 +1 |
| 인천(토론 포함) | 2 | 2 | 2 | 2 | 1 | 토론 모드가 별도 1블록 차지 |

쿼터 내 개별 선택 가중치:

```
w = w_reliability × w_year × w_novelty
  w_reliability: 확인 1.0 / 기출 0.9 / 복원 0.8 / 빈출 0.7 / 예상 0.5 / null 0.4
  w_year:        (출제연도 2024+) 1.2 / 2020~2023 1.0 / 그 이전 0.7 / null 0.9
  w_novelty:     동일 사용자 최근 3세션에 출제된 질문 0.1 (재출제 억제)
```

- 쿼터를 채울 후보가 부족한 유형은 §3-1의 필터를 한 단계 완화해 재시도, 그래도 부족하면 LLM 생성 질문으로 보충(생성 질문은 `generated: true` 마킹, 피드백 화면에 "예상 질문" 표기).
- 상황형 1문은 가급적 선택 직렬의 직렬 특화 상황형(04-jobs 파일 유래, `category == job AND type == 상황형`)에서 뽑는다.
- 발표·스피치 제시문은 이 쿼터와 별도로 `type ∈ {발표}` 풀에서 1건 샘플링(서울 트랙은 인성/시정/시사 3계열 균등 확률 — 실제로 예측이 어려운 출제 경향 재현).

### 3-3. 출제 순서

실제 면접 흐름을 모사해 고정 골격을 쓴다:

```
(인성: 자기소개류 1) → (공직가치 1) → (직무 1~2) → (지역현안 1) → (상황형 1)
→ (직무 1~2) → (공직가치 1) → (인성 1) → (지역현안 1) → WRAPUP
```

- 사전조사서/발표 추적 질문은 두 번째 슬롯에 삽입(실제 진행 순서와 동일).
- 동일 유형 3연속 금지, 상황형은 세션 중반 이후 배치(긴장도 곡선 관리).

## 4. 난이도 조절

### 4-1. 모드 정의

| 항목 | **초급 모드** (연습) | **실전 모드** (압박) |
|---|---|---|
| 질문 구성 | 기본(주)질문만, 빈출·기출 위주(`w_reliability` 높은 항목 우선) | 전체 풀 + LLM 생성 예상 질문 포함 |
| 꼬리질문 | T1(red flag), T7(미완결)만, 최대 뎁스 1 | T1~T6 전체, 최대 뎁스 3, T6 조건 변경 압박 활성 |
| 위원 페르소나 | 온화형 1인 진행(대구 트랙도 압박위원 비활성) | 트랙별 2~3인 페르소나 전원 활성(압박위원 포함) |
| 시간 제한 | 소프트 컷만(초과 허용, 피드백으로 안내) | 하드 컷 적용, 발표 5:30 강제 종료 |
| 답변 중 힌트 | 무응답 30초 시 답변 프레임 힌트 제공(예: "STAR 구조로: 상황부터") | 힌트 없음, 무응답은 skip + 감점 신호 기록 |
| 재도전 | 질문별 "다시 답변하기" 허용 | 불가(실제와 동일) |
| 채점 표시 | 요소별 코칭 중심, 미흡 판정 대신 "미흡 위험 신호"로 순화 | 우수/보통/미흡 실제 규칙 그대로(위원 과반수 상/하 조합) 판정 |

### 4-2. 진행 곡선 (권장 UX)

```
초급(질문 익히기) → 초급+꼬리질문 체험(뎁스 1 개방) → 실전(트랙 풀코스) → 실전 반복(오답 유형 집중)
```

- 실전 모드 채점 후, 사용자가 '하' 판정을 받은 평정요소의 질문 유형을 다음 세션 쿼터에 +1 가중하는 **약점 보정 샘플링**을 적용한다.
- 압박 강도는 지자체 프로파일과 곱해진다(예: 부산 트랙은 실전 모드여도 압박위원 발화 빈도 하향 — 실제 분위기 재현).

## 5. 채점·피드백 연결 (요약)

세션 종료 시 평가루브릭-설계.md §4-3 파이프라인을 그대로 호출한다:

```
① STT 전사 + 스피치 지표(말속도 350~400 CPM 기준, 필러워드, 침묵, 길이)
② LLM 채점 × 2~3 페르소나(트랙의 위원 수와 일치) → 요소별 상/중/하
③ 과반수 집계 → 우수/보통/미흡 (전요소 상 = 우수 / 동일요소 하 과반 or 2요소 하 = 미흡)
④ red flag 강제 반영
⑤ 피드백: 등급 + 요소별 근거 인용 + 스피치 코칭(비언어는 등급 미반영) + 예상 꼬리질문 + 약점 보정 다음 세션 추천
```

- 위원 수는 트랙과 일치시킨다: 국가직 2인 → 2인 앙상블(과반수=만장일치), 대구 3인 → 3인 앙상블(2/3).
- 서울 트랙은 구 5요소 평정표(공직관/커뮤니케이션/전문성/태도/의지·발전가능성)를 쓰므로, 루브릭 §2-5의 토글로 평정요소 세트를 교체할 수 있어야 한다.

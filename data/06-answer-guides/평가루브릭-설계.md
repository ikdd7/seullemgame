# AI 평가 엔진용 평가 루브릭 설계 자료

> 수집일: 2026-07-04

공무원 AI 면접 시스템의 평가 엔진(LLM 채점 + 스피치 분석) 설계를 위한 기초 자료.
공식 평정 체계(공무원임용시험령, 인사혁신처 발표), 면접 평정 해설 기사, 기존 AI 면접 서비스(뷰인터·사람인·마이다스 AI역량검사 등)의 측정 항목, LLM-as-Judge 설계 문헌을 종합.

---

## 1. 공식 평정표 구조

### 1-1. 4대 평정요소 (2024. 1. 1. 시행, 공무원임용시험령 개정)

2024년부터 국가공무원 면접의 평정요소가 기존 5개에서 공무원 인재상 기반 4개로 전면 개편되었다.

| 평정요소 | 정의 | 하위 평가역량 (인사혁신처 발표) |
|---|---|---|
| ① 소통·공감 | 국민 등과 소통하고 공감하는 능력 | 의사소통능력, 대인관계능력, 팀워크(결속력) 지향 |
| ② 헌신·열정 | 국가에 대한 헌신과 직무에 대한 열정적 태도 | 국가·공직에 대한 헌신, 적극성, 성실성 |
| ③ 창의·혁신 | 창의성과 혁신을 이끄는 능력 | 창의력, 전략적 사고력, 변화관리 |
| ④ 윤리·책임 | 공무원으로서의 윤리의식과 책임성 | 윤리의식(청렴), 책임감, 공정성 |

- 시험실시기관장이 필요 시 **평정요소를 추가**할 수 있다(예: 직무 전문지식) → 지자체·직렬별 커스텀 요소를 엔진에서 플러그인 형태로 지원할 근거.
- 구조화 면접(structured interview) 방식 자체는 유지, 세부 평가역량과 **평가 행동지표**가 요소 개편에 맞춰 조정됨.
- (참고) 개편 전 5대 요소: 공무원으로서의 정신자세 / 전문지식과 그 응용능력 / 의사표현의 정확성과 논리성 / 예의·품행 및 성실성 / 창의력·의지력 및 발전가능성. 지자체 중 일부는 자체 평정표를 쓰므로 지방직 대응 시 확인 필요.

### 1-2. 위원 평정 방식과 등급 결정 규칙 (핵심 알고리즘)

각 면접위원은 평정요소별로 **상 / 중 / 하**를 평정하고, 위원들의 평정 조합으로 응시자의 최종 등급(우수/보통/미흡)이 결정된다.

```
우수: 위원 과반수가 "모든 평정요소"에 상(上)을 평정한 경우 (유일한 경우)
미흡: (a) 위원 과반수가 평정요소 중 2개 이상에 하(下)를 평정, 또는
      (b) 위원 과반수가 "동일한 하나의 평정요소"에 하(下)를 평정
보통: 그 외의 모든 경우
```

- 위원이 2인이면 2인 모두, 3인이면 2인 이상이 "과반수".
- **우수** → 필기성적과 무관하게 최우선 합격. **보통** → 우수 인원을 제외한 정원만큼 필기성적 순으로 합격. **미흡** → 추가면접(재면접) 대상, 재면접에서도 미흡이면 불합격(면접 과락). 필기 최고득점자도 미흡이면 탈락한 판례 존재.
- 미흡 비율은 통상 10% 미만으로 알려져 있으나 실제로는 훨씬 드물다는 후기가 다수.

### 1-3. 엔진 설계 시사점

1. **점수 합산형이 아니라 임계 판정형**: 실제 제도는 "평균 점수"가 아니라 상/중/하 조합 규칙이다. AI 엔진도 요소별 3단 판정(상/중/하) 후 규칙 기반으로 등급을 산출하면 실제와 동일한 UX를 준다.
2. **비대칭 구조**: 우수는 "모든 요소 상"이라는 매우 좁은 조건, 미흡은 "하나의 치명 요소"로 성립 → **결격 신호(red flag) 탐지를 가점 탐지보다 우선**해야 한다.
3. **다면 평가 시뮬레이션**: 위원 2~3인의 과반수 규칙을 모사하려면, LLM 평가를 서로 다른 페르소나(엄격형/온화형/직무형 위원)로 2~3회 수행 후 과반수 집계하는 앙상블 구조가 제도 정합성과 채점 안정성(LLM 편차 완화)을 동시에 얻는다.

## 2. 평정요소별 측정 가능한 하위 지표 분해

LLM·음성 분석으로 측정 가능하도록 각 요소를 관찰 가능한 행동지표로 분해한 제안.

### 2-1. 소통·공감

| 하위 지표 | 측정 방법 | 상 / 하 판정 신호 |
|---|---|---|
| 두괄식 구성 | 답변 첫 1~2문장에 결론 존재 여부 (LLM) | 상: 결론 선행 / 하: 결론 부재·미괄식 장황 |
| 질문 적합성(경청) | 질문 의도와 답변 내용 일치도 (LLM) | 하: 동문서답, 준비 답변 낭독 |
| 상대방 관점 언급 | 민원인·상사·동료 등 타자의 입장·감정 언급 횟수 (LLM) | 상: "~입장에서는", "고충을 들어보고" / 하: 자기 관점만 |
| 경청·공감 표현 | "말씀을 끝까지 듣고", "충분히 이해된다" 류 표현 (LLM 키워드+맥락) | 상: 확인→공감→대응 순서 |
| 협업 지향 | 혼자 해결 vs 협의·협업 행동 포함 여부 (LLM) | 하: 독단적 처리 일변도 |
| 전달 명료성 | 문장 완결성, 지시어 남발, 발음 명료도 (LLM+음성) | 하: 문장 미완결 다수, 웅얼거림 |

### 2-2. 헌신·열정

| 하위 지표 | 측정 방법 | 상 / 하 판정 신호 |
|---|---|---|
| 공직 동기의 구체성 | 지원동기·공직관 답변에서 추상 선언 vs 경험 근거 (LLM) | 하: "안정적이라서" 단독, 부정적 공직관 |
| 적극성 표지 | "먼저", "제가 나서서", 자발적 행동 서술 (LLM) | 상: 지시 이전의 자발 행동 사례 |
| 직무·기관 이해도 | 지원 직렬 업무, 지자체 정책·현안 지식의 정확성 (LLM+지식베이스 대조) | 하: 기관 업무 오인, 현안 무지 |
| 끝까지 완수 서사 | 곤란 상황에서 포기 vs 지속 노력 서술 (LLM) | 상: 장애물→극복 행동 명시 |
| 답변 태도 에너지 | 성량, 발화 지속성, 무응답 비율 (음성) | 하: 무응답·포기성 발언("모르겠습니다"만) |

### 2-3. 창의·혁신

| 하위 지표 | 측정 방법 | 상 / 하 판정 신호 |
|---|---|---|
| 대안의 독자성 | 기존 방식 답습 vs 개선·보완 아이디어 제시 (LLM) | 상: 현행 정책 인지 + 보완 제안 |
| 전략적 사고 | 원인 분석 → 우선순위 → 단계적 실행 구조 (LLM) | 하: 나열식, 원인 분석 부재 |
| 근거 기반 제안 | 수치·사례·타 지자체 벤치마킹 인용 (LLM) | 상: 구체 근거 1개 이상 |
| 실현 가능성 | 예산·인력·법령 제약 인식 여부 (LLM) | 하: 비현실적 공약성 대안 |
| 변화 수용성 | 새로운 제도·기술에 대한 태도 (LLM) | 하: 변화 거부·냉소 |

### 2-4. 윤리·책임

| 하위 지표 | 측정 방법 | 상 / 하 판정 신호 |
|---|---|---|
| 법규·원칙 우선 | 딜레마에서 판단 기준으로 법령·공익 명시 (LLM) | 하: 사익·편의 우선, 규정 무시 |
| 책임 귀속 | 실수 상황에서 "제 책임" 인정 vs 전가 (LLM) | 하: 남 탓, 은폐 시나리오 |
| 공정성 | 형평성·특혜 배제 언급 (LLM) | 하: 연고·편의에 따른 차등 허용 |
| 청렴 신호 | 금품·청탁 상황에서 거절+보고 절차 (LLM) | 하: 애매한 수용, 절차 생략 |
| 일관성(정직) | 서면 과제·이전 답변과의 모순 탐지 (LLM, 세션 컨텍스트 대조) | 하: 진술 번복, 과장 적발 |

### 2-5. (선택) 의사표현 정확성 — 구 5요소 및 지방직 대응용

논리 구조(주장-근거-사례), 어휘 적절성, 답변 길이 적정성(30초~1분), 중복·반복률. 지방직 일부 지자체는 구 평정표를 유지하므로 별도 요소로 토글 가능하게 설계.

## 3. 스피치/비언어 평가 요소 (기존 AI 면접 서비스 측정 항목)

### 3-1. 서비스별 측정 항목

| 서비스 | 측정 항목 |
|---|---|
| 뷰인터(genesislab) | 표정, 시선 처리, 목소리 안정성, 말하기 속도(초당 발화수), 답변 논리성·구체성, 10가지 소셜스킬 점수화 |
| 사람인 AI 모의면접 | 개인 맞춤 질문·꼬리질문 생성, 면접 태도 분석(시선·음성·표정·응시 환경), 예시 답변 제공, 음성 전용 모드 |
| 마이다스 AI역량검사 | 자기소개→기본질문→성향파악→상황대처→전략게임→심층대화 구성, 뇌신경과학 기반 성향 분석 (영상은 참고자료로 면접관에게 제공) |
| 잡코리아/에듀스 등 | 답변 일관성, 집중력, 태도 변화 추적 |

### 3-2. 음성(스피치) 지표 설계안

| 지표 | 측정 | 권장 기준값 (검색 자료 기반) |
|---|---|---|
| 말속도 | 분당 글자수(CPM, 공백 제외) 또는 초당 음절수 | 발표·면접 표준 350~400 CPM. 400 초과 지속 시 "빠름", 300 미만 "느림" 피드백 |
| 침묵(무응답) | 질문 후 첫 발화까지 지연(response latency), 답변 중 2초 이상 휴지 빈도 | 첫 발화 지연 5초 이상, 장휴지 빈발 시 감점 신호. 단 2~3초 "생각 정리 후 답변"은 정상 |
| 필러워드(습관어) | "음", "어", "그", "약간", "뭐랄까" 등 간투사 빈도 | 분당 횟수 카운트, 답변당 3회 이하 목표 코칭 |
| 성량·톤 안정성 | 음량 분산, 피치 변동, 문장 끝 흐림(꼬리 낮춤) | 문장 끝 소멸 패턴 감지 → "끝맺음 명확히" 피드백 |
| 답변 길이 | 질문 유형별 발화 시간 | 일반 질문 30초~1분, 자기소개 45~55초, 5분 발표 4:30~5:00 |
| 발화 지속성 | 무응답·중도 포기("잘 모르겠습니다" 후 종료) 감지 | 무응답은 실제 미흡 판정의 최다 원인 → 강한 경고 |

### 3-3. 비언어(영상 사용 시) 지표

- 시선: 카메라(면접관) 응시 비율, 화면 밖·아래로 시선 이탈 빈도 (질문 텍스트를 읽느라 시선이 내려가는 패턴이 대표 감점).
- 표정: 무표정 지속, 미소 비율, 답변 중 급격한 표정 변화.
- 자세·태도: 고개 흔들기, 몸 흔들기 등 반복 습관 동작.
- 유의: AI역량검사 계열에서도 영상 분석은 "참고자료" 위상 → 비언어 점수는 **등급 판정에 직접 반영하지 말고 코칭 피드백 채널로 분리**하는 것이 공정성 논란(편향)을 피하는 설계.

## 4. LLM 기반 답변 평가 프롬프트 설계 가이드

### 4-1. LLM-as-Judge 설계 원칙 (문헌 기반)

1. **루브릭을 프롬프트에 명시적으로 정의**: criteria(무엇을 평가하는가) + description(각 점수대의 조건)을 구조화해 입력. 명시적 루브릭이 비공식 피드백보다 일관성·품질 모두 우수.
2. **점수 + 짧은 근거(이유) 동시 산출**: "1~5점 + 판정 근거 인용"이 표준. 근거에는 답변 원문에서의 **직접 인용(evidence)**을 포함시켜 환각 채점 방지.
3. **다차원 분리 평가**: 정확성(factuality), 관련성(relevance), 일관성(coherence), 근거성(groundedness)을 한 번에 묻지 말고 지표별로 분리 호출하거나 구조화 출력으로 분리.
4. **판정 순서**: 근거 나열 → 판정의 순서(reasoning-then-verdict)로 출력을 강제해 후광효과 완화.
5. **편차 관리**: 동일 답변 복수 채점(자기 일관성) 또는 페르소나 앙상블 후 과반수/중앙값 집계 — 1-3의 위원 과반수 규칙과 자연스럽게 결합.
6. **안전성 차원 별도 검사**: 유해성·편향(지역·성별 비하 등)은 품질 점수와 별개의 게이트로 체크.

### 4-2. 채점 기준 제안 (평정요소 × 3단 판정)

프롬프트에 넣을 판정 기준 초안. 각 요소는 §2의 하위 지표를 근거로 상/중/하를 판정.

```
[공통 입력]
- 질문 유형: 경험형 | 상황형 | 공직가치 | 지역현안 | 꼬리질문
- 질문 텍스트, 답변 전사문, (있다면) 서면 과제 내용·이전 답변 요약

[요소별 판정 기준 예 — 소통·공감]
상: 두괄식 결론 + 질문 의도에 정확히 부합 + 상대방(민원인/동료) 관점을 1회 이상
    구체적으로 언급 + 협의·경청 행동이 포함됨
중: 질문에 부합하나 상대방 관점 언급이 형식적이거나, 구조가 산만함
하: 동문서답 / 자기 관점만 존재 / 문장이 완결되지 않아 의미 전달 실패

[요소별 판정 기준 예 — 윤리·책임]
상: 법령·공익을 판단 기준으로 명시 + 책임 인정 + 절차(보고·협의) 준수 +
    상대 배려의 보완책 제시
중: 원칙은 지키나 근거 설명이 빈약하거나 기계적
하: 규정 무시/사익 우선/책임 전가/거짓·과장 정황 (→ 즉시 red flag)

[Red Flag (탐지 시 해당 요소 무조건 '하' + 전체 경고)]
- 부정적·냉소적 공직관 표명
- 위법·비윤리 행동의 정당화
- 이전 진술과의 명백한 모순 (거짓 정황)
- 무응답 또는 실질 내용 없는 답변
- 특정 집단 비하 표현

[출력 형식(JSON)]
{
  "요소별": {
    "소통공감": {"판정": "상|중|하", "근거": "...", "인용": ["답변 원문 일부"]},
    "헌신열정": {...}, "창의혁신": {...}, "윤리책임": {...}
  },
  "red_flags": [],
  "잘한_점": ["..."], "개선_점": ["..."],
  "모범답변_방향": "..."
}
```

### 4-3. 등급 산출 파이프라인 제안

```
① 전사(STT) → 스피치 지표 산출 (말속도, 필러워드, 침묵, 길이)   [규칙 기반]
② LLM 채점기 × N 페르소나 (엄격/표준/직무 위원) → 요소별 상/중/하  [LLM]
③ 과반수 집계 → 공식 규칙 적용:
   전요소 상(과반) → "우수" / 동일 요소 하(과반) 또는 2개 요소 하(과반) → "미흡" / 그 외 "보통"
④ red flag 존재 시 해당 요소 강제 '하' 반영
⑤ 피드백 조립: 등급 + 요소별 근거 인용 + 스피치 코칭(비언어는 등급 미반영) + 예상 꼬리질문
```

### 4-4. 검증·운영 유의점

- LLM 채점의 기준 일관성을 위해 few-shot으로 상/중/하 앵커 답변(각 요소당 1개씩)을 프롬프트에 포함.
- 채점 프롬프트 변경 시 고정 답변 세트(골든셋)로 회귀 테스트 — 등급 뒤집힘 비율을 모니터링.
- 실제 제도상 미흡은 드물다(체감 수 % 미만) → 엔진의 미흡 판정이 과도하면 사용자 이탈. red flag 없는 한 미흡을 보수적으로 판정하고, 대신 "미흡 위험 신호" 코칭으로 전달.
- 필기점수·스펙 등 외부 정보는 평정에 반영하지 않는 것이 제도 취지(블라인드 면접)와 일치.

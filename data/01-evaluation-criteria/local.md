# 지방직 공무원 면접 — 평정요소·방식·지자체별 차이

> 수집일: 2026-07-04 / 출처: 응시자 복원 후기 및 공개 자료 기반

## 1. 법적 근거와 평정요소

- 근거: **「지방공무원 임용령」**(면접시험은 공무원으로서의 자세 및 태도, 직무 수행에 필요한 적격성 등을 검정).
- 2024. 1. 1.부터 국가직과 동일하게 **공무원 인재상 기반 4개 평정요소**로 개편 (지방공무원 임용령 개정, 국가·지방 공통 개편).

| 평정요소 | 의미 |
|---|---|
| **소통·공감** | 국민(주민) 중심으로 소통하고 공감하며 배려하는 공무원 |
| **헌신·열정** | 적극적이며 지역과 국가에 헌신하는 열정적인 공무원 |
| **창의·혁신** | 창의적 사고로 변화에 대응하고 혁신을 이끄는 공무원 |
| **윤리·책임** | 윤리의식을 갖추고 청렴하며 책임 있게 일하는 공무원 |

- 시험실시기관장(시·도지사 등)이 필요 시 **평정요소를 추가**할 수 있음 → 지자체별로 세부 평가역량·방식이 달라지는 근거.
- 평가 등급은 국가직과 동일하게 **우수 / 보통 / 미흡** 3등급 체계.
  - 우수: 필기성적과 관계없이 우선 합격 대상 / 미흡: 필기성적과 관계없이 불합격(또는 추가면접).

### (참고) 개편 전 평정요소 (~2023, 지방공무원 임용령 구 제50조의3)
1. 공무원으로서의 정신자세
2. 전문지식과 그 응용능력
3. 의사표현의 정확성과 논리성
4. 예의·품행 및 성실성
5. 창의력·의지력 및 발전 가능성

## 2. 지방직 면접의 일반적 특징

- 장소: 대부분 지자체 청사 내 면접실(대회의실/소회의실 등).
- 면접위원: 2~3인(전문면접관 또는 인사담당자 + 현직 공무원).
- 응시자: 1인 개별면접이 기본이나, 지자체에 따라 2~3인 동시면접·발표형·토론형 병행.
- 국가직과 달리 **지역 현안·시정(도정) 질문**이 비중 있게 출제됨.
  - 예: 지역의 현재 문제점, 지역 인구감소·축제 홍보 방안, 해당 시·군 정책 사업, 전공을 공직에서 활용하는 방법 등.
- 다수 지자체에서 면접 전 **사전조사서(자기기술서)** 를 작성하게 함 (경기, 충북, 대구 등). 사전조사서 기반 개별 질문이 이어짐.
- 지역 연고 관련: 원칙적으로 블라인드 면접이나, 운영 실태는 지자체별로 편차가 있음.

## 3. 지자체별 면접 방식 차이 (응시자 후기 기반)

| 지자체 | 특징 |
|---|---|
| **서울시** | 5분 스피치(주제 검토 후 발표) + 개별면접. 자기소개서·사전조사서 작성 없음 → 나이·경력 블라인드가 비교적 잘 지켜짐. 스피치 주제는 시사, 서울시정, 인성·경험 등에서 골고루 출제(예측 난이도 높음). 연고지가 답변 중 드러나도 큰 페널티 없음. |
| **경기도** | 사전조사서 작성. 시·군 통합 면접이나 타 지역 대비 **'미흡' 비율이 높은 편**이라는 후기 다수. 면접에서 연고지 확인성 질문이 나왔다는 후기 있음. 외곽 시·군(안성·이천·여주·포천·가평·연천 등)은 상대적으로 덜하다는 평. |
| **인천시** | 2023년부터 9급 면접에 **집단토론(집단토의) 도입**. |
| **부산시** | 미흡이 거의 없고 필기합격자 대부분 최종합격하는 등 상대적으로 부담이 덜하다는 후기. |
| **대구시** | 사전조사서 작성 지자체. |
| **충북** | 사전조사서 작성 지자체. |
| **경북** | 개별면접 중심, 지역 현안(인구감소 등) 질문 비중 높음. |
| **전남 등 도 단위** | 시·군별 위탁 면접, 지역 현안·연고 관련 질문 후기 다수. |

※ 위 차이는 연도별로 달라질 수 있으므로, 응시 연도의 각 시·도 공고문(지방자치단체 인터넷원서접수센터)과 최신 복원 후기를 반드시 확인해야 함.

## 4. 지방직 면접 빈출 질문 영역
- 인성·경험 (자기소개, 봉사, 갈등 해결)
- 공직관·공직가치 (공무원의 자세, 청렴, 적극행정)
- 지역 현안·시정/도정 (지역 문제점과 해결 방안, 지역 정책·축제·관광 활성화, 인구감소·지방소멸 대응)
- 직렬 전공·직무 (전공의 공직 활용, 담당 업무 이해)
- 상황형 (민원 응대, 상사의 부당한 지시, 규정과 융통성)
